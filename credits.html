제작·출처 안내

직접 만든 부분과 외부 자료를 구분해 기록합니다. 출처 표기는 필요한 사용 허가를 대신하지 않습니다.

게임과 자체 제작물

13의 게임 코드와 요원·총기 표현, 절차적으로 생성하는 맵·재질·음향은 이 프로젝트에서 만듭니다. 챔피언스 총 모델·공격/수비 텍스처·마무리·배너·합성 음악은 저장소의 자체 생성 스크립트로 만듭니다. 제공된 JAR는 참고 자료이며 총 원본 파일을 기본 패키지에 복사하지 않습니다. 이 설명은 제작 경로를 말하며 다른 작품의 보호되는 외형·음악·상표에 대한 허가를 주장하는 문구가 아닙니다.

칼 디자인

SGH나비칼의 모양과 텍스처는 이 프로젝트의 생성 스크립트로 만듭니다. 손잡이가 돌아가는 동작과 관련 소리는 사용자가 유지하도록 지정한 예외로, 제공된 Knife Pack의 나비칼 애니메이션·소리를 그대로 사용하며 자체 창작물로 표시하지 않습니다. 나머지 칼 10종은 이 프로젝트에서 형상을 생성하고 기존 손 위치와 모션을 유지합니다. 파일별 제작 경로와 지문은 패키지 manifest와 자산 출처 기록으로 관리합니다.

맵과 블록 표현

공개 맵 목록의 맵은 모두 이 게임이 직접 만든 배치입니다. 다른 게임의 맵 구조를 바탕으로 한 개발용 맵(황혼 지구)은 2026년 11월 7일부터 공개 목록과 이 사이트에서 뺐습니다. 사막 마을은 삭제 상태를 유지합니다.

사진 재질과 하늘 조명

표면 재질은 ambientCG와 Poly Haven의 CC0 자료를 바탕으로 크기와 채널을 게임에 맞게 가공했습니다. 하늘 조명도 Poly Haven HDRI를 사용합니다. 세부 원본 이름과 가져온 경로는 저장소 assets/CREDITS.md에 기록합니다.

글꼴과 라이브러리

제목과 큰 숫자에 갈무리11 Bold를, 본문에 Pretendard Variable을 사용합니다. 두 글꼴은 SIL Open Font License에 따라 제공하며 갈무리 라이선스와 Pretendard 라이선스를 함께 배포합니다. 게임의 일부 연출과 지도 표시는 Google Fonts의 Orbitron과 Noto Sans KR을 사용합니다. 3D 렌더링에는 Three.js(MIT), 연결에는 PeerJS(MIT)를 사용합니다. 외부 서비스의 접속 정보 처리는 개인정보 안내에 설명합니다.

비공식 독립 프로젝트

이 게임은 개인이 운영하는 독립 프로젝트입니다. 다른 게임 회사의 공식 서비스나 제휴·후원·승인을 받은 서비스라고 표시하지 않습니다. 비공식이라는 안내만으로 제3자의 콘텐츠를 사용할 권한이 생기지는 않습니다.

사용 범위 확인

황혼 지구 구조와 SGH나비칼의 유지한 뼈대·모션·음원은 웹 게임 재배포와 광고 수익화까지 허용된 범위를 추가 확인 중입니다. 현재 광고는 실행하지 않습니다. 필요한 허가가 확인되지 않으면 해당 자료를 교체하거나 제공 범위를 조정합니다.

권리 문의

자신의 제작물이 포함되었다고 생각하거나 라이선스 기록을 확인하려면 문의 페이지에서 대상 파일·화면·원본 주소와 권리 범위를 알려 주세요. 비공개 계약서·개인정보·계정 비밀번호를 공개 글에 적을 필요는 없습니다. 운영자는 출처와 사용 범위를 확인해 필요한 수정·교체를 진행합니다.
