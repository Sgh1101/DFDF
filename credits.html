제작·출처 안내

직접 만든 부분과 외부 자료를 구분해 기록합니다. 출처 표기는 필요한 사용 허가를 대신하지 않습니다.

게임과 자체 제작물

13의 게임 코드와 요원·총기 표현, 절차적으로 생성하는 맵·재질·음향은 이 프로젝트에서 만듭니다. 챔피언스 총 모델·공격/수비 텍스처·마무리·배너·합성 음악은 저장소의 자체 생성 스크립트로 만듭니다. 제공된 JAR는 참고 자료이며 총 원본 파일을 기본 패키지에 복사하지 않습니다. 이 설명은 제작 경로를 말하며 다른 작품의 보호되는 외형·음악·상표에 대한 허가를 주장하는 문구가 아닙니다.

칼 디자인

RGX 나비칼은 사용자가 유지하도록 지정한 예외로, 제공된 Knife Pack의 RGX 11z Firefly 모델·텍스처·애니메이션·관련 소리를 선별해 사용합니다. RGX는 자체 창작물로 표시하지 않습니다. 나머지 칼 10종은 이 프로젝트에서 형상을 생성하고 기존 손 위치와 모션을 유지합니다. 파일별 제작 경로와 지문은 패키지 manifest와 자산 출처 기록으로 관리합니다.

맵과 블록 표현

마크X발로은 직접 설계한 배치와 생성 코드로 지형·충돌을 만듭니다. 사막 마을은 삭제 상태를 유지하며, 하늘섬의 이전 schematic 형상은 독립적인 배치로 교체했습니다. 블록 텍스처는 재료별 단색으로 직접 그린 이미지입니다. Minecraft 원본 텍스처 묶음을 배포한다는 뜻이 아닙니다. 제작 경로와 교체 이력은 프로젝트의 자산 출처 기록으로 관리합니다.

사진 재질과 하늘 조명

표면 재질은 ambientCG와 Poly Haven의 CC0 자료를 바탕으로 크기와 채널을 게임에 맞게 가공했습니다. 하늘 조명도 Poly Haven HDRI를 사용합니다. 세부 원본 이름과 가져온 경로는 저장소 assets/CREDITS.md에 기록합니다.

글꼴과 라이브러리

Google Fonts의 Black Han Sans·Orbitron·Noto Sans KR은 해당 SIL Open Font License에 따라 사용합니다. 3D 렌더링에는 Three.js(MIT), 연결에는 PeerJS(MIT)를 사용합니다. 외부 서비스의 접속 정보 처리는 개인정보 안내에 설명합니다.

비공식 독립 프로젝트

이 게임은 개인이 운영하는 독립 프로젝트입니다. 다른 게임 회사의 공식 서비스나 제휴·후원·승인을 받은 서비스라고 표시하지 않습니다. 비공식이라는 안내만으로 제3자의 콘텐츠를 사용할 권한이 생기지는 않습니다.

권리 문의

자신의 제작물이 포함되었다고 생각하거나 라이선스 기록을 확인하려면 문의 페이지에서 대상 파일·화면·원본 주소와 권리 범위를 알려 주세요. 비공개 계약서·개인정보·계정 비밀번호를 공개 글에 적을 필요는 없습니다. 운영자는 출처와 사용 범위를 확인해 필요한 수정·교체를 진행합니다.

설치 없이 지금 바로브라우저에서 한 판 해 보세요. 혼자서는 AI와, 친구와는 초대 코드로 함께 즐길 수 있습니다.
