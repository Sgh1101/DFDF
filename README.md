# 13

브라우저에서 바로 돌아가는 5대5 전술 FPS. 오리지널 요원 7명, 무기 20종, 맵 4종.
외부 이미지·사운드 파일이 하나도 없습니다. 텍스처·초상화·효과음을 전부 코드로 만듭니다.

## 올리는 방법

1. GitHub에서 새 저장소를 만듭니다 (Public으로).
2. 이 폴더의 파일 4개를 올립니다.
3. https://vercel.com 에서 **Add New → Project → 저장소 선택 → Deploy**.
4. 끝. 주소가 나오면 친구에게 보내면 됩니다.

Vercel 설정은 건드릴 필요 없습니다. 정적 사이트로 자동 인식됩니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 소개 페이지 |
| `play.html` | 게임 본체. 이 파일 하나에 전부 들어 있습니다 |
| `vercel.json` | 배포 설정 |
| `README.md` | 이 문서 |

`play.html`은 더블클릭해도 바로 실행됩니다. 다만 **친구와 하려면 웹에 올려야 합니다.**

## 친구와 하기

초기 화면에서 **친구와 하기**를 누르면 6자리 방 코드가 나옵니다.
친구는 **코드로 참가**에 그 코드를 넣으면 됩니다.

- 방을 만든 사람이 호스트입니다. 게임 계산은 호스트 한 곳에서만 돌아갑니다
- 대기실에서 공격 5칸 / 수비 5칸 중 빈 자리를 눌러 팀을 옮깁니다
- 요원은 팀 안에서 중복해 고를 수 없습니다
- 두 팀의 사람 수 차이가 3 이상 벌어지는 이동은 막힙니다
- 남는 자리는 AI가 채웁니다
- **게임 도중에 들어와도 됩니다.** AI가 하던 캐릭터를 그대로 이어받습니다.
  체력·위치·무기·크레딧이 전부 승계됩니다
- 누가 나가면 다시 AI가 이어받습니다
- 방장이 나가면 방이 닫힙니다

통신은 브라우저끼리 직접 연결(WebRTC)합니다. 따로 서버를 두지 않아 유지비가 0입니다.
접속 중개에 PeerJS 공개 서버를 쓰는데, 이 부분만 인터넷 연결이 필요합니다.

## 무기 균형

저격총 계열(저격총 145, 지정사수총 92)은 그대로 두고 나머지 18종의 피해량을 약 12% 낮췄습니다.
교전이 조금 더 길어지고, 첫 발을 맞아도 반격할 여지가 생깁니다.

## 맵

| 맵 | 성격 |
|---|---|
| 연화원 | 3사이트. 한국식 정원. 회전 통로 구조 |
| 한옥 시장 | 2사이트. 야간. 좁은 골목이라 사거리가 짧습니다 |
| 폐사찰 | 3사이트. 고저차가 커서 위아래 각이 갈립니다 |
| 해안 포구 | 2사이트. 개활지. 롱앵글이 열려 저격이 강합니다 |

맵은 대기실에서 방장이 고릅니다.

모든 맵에 엄폐물과 구조물을 크게 늘렸습니다. 미드에는 일직선 사격을 끊는 지그재그 엄폐물과
시야를 가리는 기둥을, 진입로와 사이트 안쪽에는 몸을 숨길 자리를 넣었습니다.
특히 개활지인 해안 포구는 컨테이너를 어긋나게 배치해 롱앵글을 잘랐습니다.

## 조작 모드 전환

화면 오른쪽 아래 **모바일 조작** 버튼으로 언제든 바꿀 수 있습니다. **M 키**로도 됩니다.

- **꺼짐** — 마우스로 시야를 돌립니다. 화면을 클릭하면 마우스가 고정됩니다
- **켜짐** — 화면에 가상 조이스틱과 버튼이 뜹니다

터치스크린이 달린 노트북에서 모바일 조작이 잘못 켜지던 문제를 고쳤습니다.
선택한 모드는 브라우저에 저장되어 다음에 들어와도 유지됩니다.

마우스가 고정되지 않으면 화면 가운데에 안내가 뜹니다. 아무 데나 클릭하면 다시 고정됩니다.

## 규칙

13라운드를 먼저 따면 승리. 12라운드가 끝나면 공수를 바꿉니다.
스파이크 설치 4초, 해제 7초이고 절반까지 해제했다면 그 지점에서 다시 시작합니다.
죽으면 아군 시점으로 넘어가 관전합니다.

요원·맵·무기 전부 오리지널입니다. 기존 게임의 요원이나 맵을 가져오지 않았습니다.
