# 외부 무기 팩 제거 (2026-10-31)

예전에 `assets/valorant-packs/`에 있던 외부 총 9종·칼 6종 팩(모델·텍스처·소리)과 그 포장 스크립트를 광고 도입 전에 모두 지웠습니다. 다른 회사의 지식재산이고 팩 자체도 비영리·변경 금지 또는 모든 권리 보유 표기였기 때문입니다.

- 총은 게임 자체 빌더(`GUN_BUILD`)의 모델과 `SFX.gun`의 합성 소리를 씁니다. 이름·성능·예전 키 통합은 `js/valorant-data.js`(내부 이름, 저장 기록 호환용)와 `js/weapon-identity.js`에 있습니다.
- 표시 이름을 우리 이름으로 바꿨습니다: 클래식→참새, 고스트→부엉이, 셰리프→황소, 밴달→표범, 저지→멧돼지, 오딘→코뿔소, 아웃로→송골매, 오퍼레이터→독수리. 팬텀(`scout`)은 챔피언스 스킨이 그 이름을 쓰므로 소유자 승인 전까지 그대로 둡니다. 키(`pistol`, `rifle` …)와 성능은 바뀌지 않았습니다.
- 팩의 칼 스킨 6종(`vp_*`)은 카탈로그에서 빠졌습니다. 가진 계정은 다음에 기록을 읽거나 저장할 때 한 개당 상점 전설 칼 가격(`shop.price.legendary × shop.knife`, 기본 22,500골드)을 한 번 돌려받고, 장착·찜에서도 빠집니다(`api/v1.js`의 `ensureWallet`, `tests/weapon-lineup.test.js`).
- 서비스 워커는 이미 받아 둔 팩 파일을 자산 캐시에서 지웁니다(`sw.js`의 `REMOVED`).
- 챔피언스 팬텀은 자기 자산(`assets/champions-phantom/`)만 쓰고 이 팩에 의존하지 않습니다.
