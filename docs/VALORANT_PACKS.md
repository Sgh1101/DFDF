# 제공된 무기 팩 적용

`Valorant_gunpack_v0.1.4_beta3_fix1`의 기본 총 9종과 `Valorant Knife Pack-0.1.0`의 칼 6종을 DFDF에 연결합니다. 이 문서는 보존한 원본과 게임 적용 범위를 설명합니다.

## 총과 보유 정보

| 게임 ID | 새 기본 모델 |
| --- | --- |
| pistol | 클래식 |
| silenced | 고스트 |
| revolver | 셰리프 |
| rifle | 밴달 |
| scout | 팬텀 (원본 모델·30발 자동사격) |
| autoshot | 저지 |
| hmg | 오딘 |
| marksman | 아웃로 |
| sniper | 오퍼레이터 |

**총기 18종과 별도 나이프**를 제공합니다. 구매창은 보조 5·기관단총 2·산탄총 2·소총 5·저격소총 2·중화기 2종입니다. 새 코멧 소총(`bullpup`)은 뒤쪽 탄창·속이 빈 개머리판·환기구·구리 방열판을 갖춘 독립적인 DFDF 모델이며 30발·750 RPM의 자동 소총입니다. 예전에 통합한 bullpup 스킨은 보관 목록에서 한 번만 돌려줍니다. 나머지 `handcan→revolver`, `stinger→pistol`, `vector/pdw/burstsmg/ripper→smg`, `slugger→shotgun`, `doublebarrel→pocketshot`, `battle→rifle`, `lmg/minigun→hmg`, `antimat→sniper` 통합은 유지합니다.

이전에는 표시 이름만 바뀌어 팬텀이 단발 정찰 소총처럼 동작했습니다. 이제 **팬텀(scout)은 원본 Phantom 모델·발사음·애니메이션, 30발·660 RPM 자동사격**을 사용합니다. 챔피언스 공격/수비도 같은 자동사격 성능입니다. 점사소총은 기존 모델과 3점사를 유지합니다. 정찰 소총(carbine)은 스코프·15발 단발 정밀사격으로 구분합니다. 팬텀의 정찰용 스코프 화면은 제거했습니다. 원본 팩 485개 파일은 보존하고 등록 manifest의 대상 키만 수정합니다. 서비스 워커가 예전 등록 정보를 재사용하지 않도록 manifest 요청 버전도 변경합니다. 네트워크의 기존 인덱스를 재정렬하지 않고 누락된 활성 총 ID를 뒤에 추가하므로 팬텀·코멧도 스냅샷에서 권총으로 바뀌지 않습니다.

서버는 기존 보유 스킨을 통합 총으로 옮기고 원래 보유 목록을 `weaponArchive`에 남깁니다. 같은 스킨이 이미 있으면 기존 중복 환급 기준으로 한 번만 보상합니다. 대상 총의 장착 선택을 우선 보존하고 빈 선택은 이전 장착으로 채우며 위시리스트도 통합합니다. 기존 rifle·carbine에 보유하거나 장착했던 챔피언스 공격·수비 스킨은 **팬텀(scout)**으로 무료 이전합니다. 일반 스킨과 대상 총의 기존 장착 선택, 코인·골드는 유지하며 기존 구매분을 다시 구매할 필요가 없습니다.

복원된 총은 보관된 원래 스킨을 현재 보유 목록과 합쳐 한 번만 돌려줍니다. 현재 장착·통합된 총에 이전한 복사본·이미 지급한 중복 보상은 유지합니다. 이후 의도적으로 회수한 스킨이 로그인마다 다시 생기지 않도록 총별 복원 여부를 기록합니다.

탄창·연사·자동 사격·재장전 시간은 팩 데이터를 사용하고 가격·피해·사거리는 DFDF 밸런스를 유지합니다. 기존 특수 스킨은 유지됩니다. 추가 namespace의 Crystal Industry 변형은 자료로 보관하며 별도 총으로 등록하지 않습니다.

## 기본 부착 스코프

오퍼레이터와 아웃로는 총 데이터의 `builtin_attachments.scope`를 따라 원본 부착물 인덱스·표시 설정·모델·텍스처를 함께 불러옵니다. 각각 273개·127개의 원본 큐브를 유지하고 `scope_pos` 뼈대에 붙이므로 재장전 때도 원래 장착 위치를 따릅니다. 구매 카드·상세 미리보기·스킨 창·손에 든 총은 같은 조립 모델을 사용합니다. 스코프 파일도 기존 원본 SHA-256 검사 대상입니다.

물리 스코프 본체와 마운트는 표시하며, TACZ의 렌즈 스텐실과 조준선 전용 평면은 일반 총 모델에서 숨깁니다. 우클릭 조준은 DFDF의 기존 확대·조준경 화면을 사용하고 피해·탄창·가격·배율을 바꾸지 않습니다.

## 칼 스킨

욕망의 검, 영원의 도끼, 영원의 카람빗, 미래 나비칼, 미래 단검, 천둥 망치를 전설 등급의 **나이프 전용 스킨**으로 등록합니다. 무기 성능과 피해량은 기존 나이프와 같습니다. 스킨 창 미리보기와 실제 장착은 같은 원본 모델을 사용합니다.

## 경기 장비 구매창

보조·기관단총·산탄총·소총·저격소총·중화기와 방어구를 열로 배치하고 하단에서 스킬·수류탄을 구매합니다. 나이프는 계속 기본 보유하며 구매 카드로 판매하지 않습니다. 총 카드는 실제 장착 모델로 만든 실루엣이고, 마우스나 키보드 포커스로 선택한 장비를 오른쪽에서 확인합니다. 카드 클릭 또는 오른쪽 구매 버튼으로 구매합니다.

오른쪽은 원본 해상도의 모델·텍스처를 Three.js로 직접 렌더링하며 장착한 챔피언스 등 스킨도 반영합니다. 이름·가격·연사·탄창·사거리·거리 보정 전 기본 피해를 게임 데이터에서 읽습니다. 보유·잔액 부족·구매 단계 종료를 구분하며 이미 가진 총과 낮은 방어구에는 중복 과금하지 않습니다. 온라인 손님은 기존 호스트 구매 메시지를 전송하고 호스트 결과가 도착하면 목록을 갱신합니다.

가로 모바일은 카테고리와 오른쪽 설명을 유지하고 세로 모바일은 2열 목록 아래 상세 패널을 배치합니다. 미리보기는 선택·크기 변경 시에만 다시 그리며 카드 이미지는 순서대로 생성하고 캐시합니다.

## 원본과 런타임

`assets/valorant-packs/v1/manifest.json`은 JSON·PNG·OGG 485개, 15,816,481바이트의 SHA-256과 출처 경로를 기록합니다. 파일을 다시 저장하거나 텍스처 해상도를 낮추지 않습니다. classic에 선언된 `classic_n.png`는 제공된 원본에도 없어 선택 항목 누락으로 기록합니다.

원본의 Bedrock 뼈대·큐브·UV와 수치 키프레임을 기존 Three.js 엔진으로 읽습니다. TACZ의 Y-down 좌표에서 Three.js의 Y-up 좌표로 옮길 때 X·Z 회전 부호를 변환하며, 기본 뼈대 회전 뒤에 애니메이션 회전을 합성합니다. 원본 JSON은 변경하지 않고 렌더링용 사본만 변환합니다. 칼 미리보기는 손에 쥐는 상위 뼈대 자세를 풀어 옆면을 보여주며 실제 장착에서는 원본 자세·동작을 적용합니다. 크기가 0인 숨겨진 효과 부품은 미리보기 크기 계산에서 제외합니다. DFDF 손과 겹치는 원본 마인크래프트 손 큐브는 표시하지 않으며 무기 본체와 원본 파일은 보존합니다. 게임 카메라에 맞춰 전체 배율·장착 위치를 조정합니다. 발사·재장전·꺼내기·Y 살펴보기와 칼 공격을 연결하고, 칼 공격 애니메이션은 기존 공격 주기에 맞춰 재생합니다. 원본 OGG를 게임 오디오 출력에 연결합니다.

Minecraft 모드 자체를 실행하는 방식은 아닙니다. Lua·Java·셰이더 코드·Molang 수식은 실행하지 않으며 수치로 표현된 애니메이션만 해석합니다. 모드의 모든 외부 효과·특수 이벤트를 동일하게 재현했다고 보장하지 않습니다. 제작자·권리 표기는 원본 `gunpack_info.json` 등에 보존합니다. gunpack의 제작자 표기는 幻梦星璇, 라이선스 표기는 CC BY-NC-ND 4.0입니다. Minecraft 텍스처의 권리는 원 권리자에게 있습니다.

## 재생성과 확인

```sh
node scripts/package-valorant.js <gun-folder> <knife-folder>
npm run check
npm test
npm run test:valorant
npm run test:valorant-scopes
npm run test:weapon-shop
```

브라우저 검사에는 실행 중인 개발 서버와 Playwright/Chromium이 필요합니다. `DFDF_BASE_URL`, `DFDF_PLAYWRIGHT_MODULE`, `CHROME_BIN`을 기존 검사와 동일하게 설정합니다.

단위 검사는 모든 원본 파일 해시, 15종 모델의 큐브 수와 애니메이션, 데이터 해석, 무기 통합과 중복 환급의 중복 실행 방지를 확인합니다. 브라우저 검사는 실제 스킨·구매 UI, 6종 칼 미리보기와 장착, 원본 공격 움직임, 원본 발사 오디오 스케줄링과 탄약 감소, 챔피언스 팬텀 호환성을 확인합니다. 구매는 메모리 API를 사용한 테스트이며 실제 결제 검증이 아닙니다. Android 실기기·온라인 혼합 버전 클라이언트는 검증하지 않았습니다.
