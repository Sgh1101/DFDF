# 발사형 능력의 높이와 조준 수정

사용자 요청: 레이저와 투사체가 캐릭터에서 출발하고 상하 조준을 따르게 고친다.

진단: 세 요원 모듈의 scan/pick이 yaw만 읽고 눈 높이를 y+1.45로 계산한다. 일부 곡사체는 비행 중 매 프레임 지면 높이를 다시 더하며, 공통 투사체는 눈 높이를 BODY_K로 나눠 캐릭터와 다른 높이에서 출발한다. 기존 궁극기 조준/광선 판정은 pitch, 캐릭터 높이, 앉기와 장애물을 이미 처리한다.

수정 기준: 기존 궁극기 광선의 캐릭터 판정을 공통 발사형 조준에 재사용한다. 벽·바닥·천장은 실제 collider 상자와 광선의 교점으로 자른다. 이동 충돌의 2.3m 여유 높이를 광선에 적용하지 않는다. 판정은 캐릭터 눈에서 조준하고 시각적 발사점은 해당 캐릭터의 시전 손을 사용한다. 손 모델이 없으면 조준 방향 기준 손 위치로 대체하고, 손이 벽 너머에 있으면 눈 위치에서 출발한다. 바닥 장판/설치물은 지면 기준을 유지한다. 사거리 배율을 중복 적용하지 않는다. 네온 전용 동작, 챔피언스, 다른 작업 폴더는 변경하지 않는다.

## 검증 기록

- 단위 RED: 기존 코드에서 최초 11개 실패. 물약/곡사 화살의 첫 프레임, 부메랑 상하 방향, 얇은 천장과 벽 너머 손 생성도 각각 실패를 확인한 뒤 수정했다.
- 단위 GREEN: `node --test tests/ability-aim.test.js` 17개 통과. `npm test`는 최신 main 반영 전 484개 중 482개 통과, 외부 Redis 선택 검사 2개 건너뜀, 실패 0개.
- 브라우저: 설치된 Chrome에서 `npm run test:ability-aim` 통과. 실제 광선 mesh 10회, 투사체 6회, 곡사체 2회, 층 차이 명중, 원격 cast 이벤트 재생, 병원 실제 천장 2개 층을 검사했다. 원격 검사는 실제 이벤트 재생이며 외부 WebRTC 접속 검사가 아니다.
- 브라우저 회귀: `browser-ability-motions.js`에서 현재 능력 107개의 손/보조 손/효과 정리 및 타인 시점 모션 통과. `browser-ascent-abilities.js`에서 마크X발로 맵 112개 능력 시전, 장판·덫의 층 구분, 4가지 그래픽 모드의 지면 검사 통과.
- 구문 및 CSP 검사 통과. 자산 원본은 변경하지 않았다. Android 실기기·실결제 검사는 실행하지 않았다.
- 실행 파일: `tests/ability-aim.test.js`, `scripts/browser-ability-aim.js`. 상세 브라우저 수치: `test-results/ability-aim/results.json` (Git 제외).
