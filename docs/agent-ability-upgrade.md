# 요원 능력 개선 계획 — 2026-10-19

## 범위와 완료 기준

현재 런타임은 43명/172개다. 과거 60명 로스터 파일을 기준으로 세지 않는다.
거미 E의 준비→발사→실제 이동→해제→정리를 기준으로, 각 능력에 읽을 수 있는
손동작과 도구, 상대가 보는 동작, 효과의 시작과 종료를 연결한다. 거미의 물리와
네온의 원본 모델/클립은 보존한다. 이름·색·수치만 다른 궁극기는 완료로 보지 않는다.

공유되는 피해/회복/탐지 같은 기본 판정은 허용하되, 궁극기의 **주된 입력과 결과,
공간적 작동 방식, 상대의 대응**이 같으면 중복으로 판정한다.

## 먼저 고칠 중복

- 뇌하/네온: 지속 전기 빔 중복. 뇌하는 전하를 모아 한 대상에서 가까운 적으로
  순차 연결되는 연쇄 방전으로 변경. 네온만 조준하며 유지하는 전기 빔을 사용한다.
- 군봉/회로: 4개 자동 추적체 중복. 군봉은 조준 지점에 파괴 가능한 여왕을 설치하고
  그 영역을 지키는 벌을 순차 출격시킨다. 회로는 4개의 소모성 추적 폭발 드론을 유지한다.
- 무영/송골/영월: 주변 적을 계속 드러내는 용도 중복. 무영은 전역 추적,
  송골은 실제 매의 예고된 급강하(피할 수 있음), 영월은 아군의 탐지를 막는 달빛 은폐.
- 울림/장판 군: 원 안에서 계속 근시·뇌진탕을 거는 효과를 제거한다.
  울림의 음벽은 바깥에서 안으로 들어오는 일반 총격을 흡수하고 파동으로 방출한다.
  개인 피해 반사인 관문 C와 달리, 적에게 피해를 되돌리지 않는다.
- 덩굴/거미/약초: 느려지는 원형 장판+치유 묶음을 분리한다.
  덩굴은 적 두 명을 잇는 끊을 수 있는 덩굴 결속, 거미는 오래 머문 적을 묶는 거미굴,
  약초는 한정된 치유량을 다친 아군에게 분배하고 상태 이상을 씻는 정원으로 구분한다.
- 백호 응시에서 전역 탐지를 제거한다. 관통 활의 조준과 세 발 운용이 핵심이다.

## 일반 능력 점검

연막은 투사/원격/이동/치유/적 표식/근시/피해의 사용법이 다르다. 치유는
설치 씨앗·움직이는 구름·자동 물약·1회 주머니로 구분한다. 덫도 접촉·소리·선 통과·
수면 해제 조건이 다르다. 같은 색의 구체로 뭉뚱그리지 않고 도구와 손동작을 구분한다.
실제 런타임의 172개 정의/설명/처리기를 대조한 기준 파일은 검사 시 생성한다.
명칭이 다른 동일 type은 허용하지 않으며, 새 능력 추가 시 이 표와 동작 검사를 같이 수정한다.

## 구현 순서

1. 독립된 능력 표현 카탈로그: 43개 테마, Q/E/C/X별 도구·행동·발동 단계.
2. 위 중복 궁극기의 실제 판정 교체. 피해·치유는 호스트 권한으로만 적용.
3. 1/3인칭 손/몸체와 도구를 같은 발동 단계에 연결. 취소/실패 시 복귀.
4. 휴대폰/성능/비주얼/최고에 표현 수와 거리를 제한. 위험 범위는 생략하지 않는다.
   추가 광원/그림자 없이, 카메라 흔들림·축소 동작 설정을 존중한다.
5. 전체 카탈로그 단위 검사, 브라우저 실제 입력, 변경된 궁극기의 기계적 차이,
   상대 화면 재생과 피해 중복 방지, 사망·라운드 전환·효과 자원 해제 검사.
6. 기존 거미/네온/무기/그래픽 회귀 검사 후 최신 Claude 변경을 확인하고 배포.

## 구현 결과와 검증

- `ability-profiles.js`가 최종 로스터의 43명/172개와 대응한다. 등록 누락이나 같은
  type 재사용은 조용히 일반 효과로 대체하지 않고 초기화 오류로 검출한다.
- 거미 E/네온 4개 원본 동작, 기존 궁극 무기 5개를 보존했다. 나머지 162개에는
  테마 도구·손동작·상대 몸 동작을 연결했다. 손과 도구는 같은 손목 좌표계에 있다.
  지연 투사체/판정에도 최초 능력의 피격 표현이 전달된다.
- 궁극기 8개(뇌하·군봉·덩굴·울림·송골·영월·약초·백호)의 실제 행동을 위 계획대로
  분리했다. 게임 내 이름/설명도 함께 갱신했다. 기본 피해/회복 같은 판정은 공유한다.
- 새 발동 도구 큐와 피격 장식 큐 각각의 상한은 휴대폰/성능/비주얼/최고에서
  6/10/16/20이다. 기존 판정 효과를 이 숫자로 제한하지 않는다. 거리 밖 장식은
  생략하며, 품질을 낮추면 초과 장식을 정리한다. 판정/위험 경계는 그대로 남는다.
  새 광원이나 그림자는 추가하지 않았다.

실행한 검사:

- 단위: 136개 중 135개 통과, 실제 Redis 연결 선택 검사 1개 제외.
- 브라우저: 최종 172개 능력 발동, 원본 보존 분기, 새 궁극기의 거리·시야·파괴·
  회피·피해/치유·사망/라운드 정리. 162개 도구의 실제 정점이 1280×720,
  844×390, 568×320 화면 안에 들어오는지 확인.
- 실제 로컬 WebRTC 두 브라우저: 호스트/게스트의 동일 cast ID, 게스트 궁극기
  충전/피해 1회 처리, 여왕 총격 파괴의 상대 화면 반영, 피격/뇌진탕 이벤트 전달.
  별도로 client 모드에서는 새 궁극기가 권한 있는 체력을 변경하지 않는지 검사.
- 관련 회귀 10개: 거미 이동, 네온 원본 재현/온라인, 가면·심판, 요원/손 디테일,
  4단계 그래픽, 맵 성능, 주요 게임 회귀, 소총 구분, 모바일 스킨 미리보기 통과.
- 구문: 외부 스크립트 152개와 play/index/admin 인라인 스크립트 통과.

앞선 모바일 미리보기 배포에는 전체 기능 브라우저 검사 65개와 UI 감사 2개를
실행했다. 위 능력 변경 이후에는 위에 적힌 능력 전수 발동과 관련 회귀를 실행했다.
두 실행 범위를 혼동하지 않는다. 실제 Android 기기·외부 인터넷 회선의 핑/FPS·
실결제는 이번 검사 범위가 아니다. 성능 수치는 브라우저 검증 결과이며 실기기 FPS로
환산하지 않는다. 대규모 대전의 수치 밸런스는 플레이 결과를 보고 추가 조정한다.
