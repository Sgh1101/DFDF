# 개인정보 문의 처리 절차

1. 문의 분류가 열람·삭제·정정인지 확인하고 접수 번호로 상태를 기록한다. 가능한 한 대상 계정으로 로그인해 보낸 요청을 사용한다.
2. 문의 기록의 보낸 계정과 대상 아이디가 같은지 확인한다. 아이디만 아는 제3자의 요청으로 삭제하지 않는다. 비밀번호 원문·신분증·결제 정보를 공개 문의에서 요구하지 않는다.
3. 게스트·로그인 불가 상황에서는 공개 글에 비밀 정보를 추가하지 말도록 안내하고 안전한 본인 확인 방법을 정한다. 자동으로 본인 확인되었다고 표시하지 않는다.
4. 삭제할 계정·진행·전적·보유 아이템의 범위와 복원 불가 여부를 요청자와 확인한다. 그 후 운영자 기능을 사용한다. 이 문서는 운영자 삭제 버튼을 자동 실행하지 않는다.
5. 현재 계정 삭제 기능의 대상 외에 문의 본문/연락처, 계정 활동 로그, 공통 운영 로그, 시즌별 기록에 관련 정보가 남는지 확인한다. 계정 삭제 버튼 하나가 모든 저장소를 지운다고 보장하지 않는다. 남겨야 하는 운영 기록이 있다면 이유와 보관 범위를 설명하고 불필요한 식별자를 제거한다.
6. 같은 문의 경로로 완료·부분 완료·추가 확인 상태를 안내한다. 호스팅/연결 제공자 로그처럼 서비스가 직접 삭제할 수 없는 정보는 해당 제공자의 절차를 안내한다.

## 현재 코드의 보관 기준

- 계정/진행: 계정 유지 동안 저장. 공통 기간 만료 없음.
- 문의 항목과 계정별 문의 인덱스: 마지막 저장 기준 TTL 90일. 답변/상태 변경으로 저장하면 TTL이 다시 설정될 수 있음.
- 계정별 활동: 최근 500건, 마지막 활동 기록 추가 기준 TTL 180일.
- 공통 운영 로그: 최근 5,000건 제한, 별도 날짜 TTL 없음.
- 순위표/시즌/경기/제공자 로그는 저장소마다 다르므로 요청 범위에 맞춰 확인한다. 미래의 임의 보관 기간을 현재 적용된 것처럼 적지 않는다.
