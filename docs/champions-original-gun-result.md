# 챔피언스 원본 총 외형 복원 결과

사용자가 선택한 범위: 처음 제공한 JAR 원본의 총 모양·비율·색상.

`ChampionsPhantom2026-0.1.0.jar`의 총 JSON과 공격·수비 기본/발광 PNG 네 장을 기본 패키지에 원본 바이트 그대로 포함한다. 원본은 33개 뼈대·878개 큐브이며 512×512 텍스처, 면별 UV, 피벗·회전 및 빈 부착 뼈대를 보존한다. 출처·SHA-256은 `scripts/champions-phantom/source-gun/provenance.json`에 기록했다. Java 코드는 실행하지 않는다.

이전 자체 제작 총의 17개 뼈대·132개 큐브를 원본으로 대체했다. 파일 재생성 시에도 동일한 원본 바이트가 나오며, 원본 색표로 처치 물결을 판정한다. 기존 장착 대상 팬텀(scout), 보유·구매·코인·무기 성능을 유지한다. 음악·마무리·배너·모션의 패키지 바이트는 기준 main `79b08d5`와 동일하다.

## 검증

- RED: 기존 패키지가 원본 해시 및 33개 뼈대 조건에 맞지 않아 새 검사 2개가 실패했다.
- GREEN: 원본 다섯 파일, 원본/패키지 일치, 패키지 재현성, 기존 캐시 회피 및 처치 색표 검사 9개 통과.
- 전체 단위 467개: 465개 통과, 실패 0개, 실제 Redis 2개 건너뜀.
- 문법 검사와 시각 파일 39개 해시·길이 검사 통과.
- 브라우저 6종: champions-concept, phantom(JAR 교체 포함), phantom-carbine, phantom-kill-wave, phantom-loading, phantom-audio 모두 통과. 게임 트리 SHA-256은 `a5c1b41c18ba0857c7a4b58613d5ccf3c0516ea8986386d6fc534a2640f34e06`.
- 첫 브라우저 실행은 이전 자체 디자인의 진홍/상아 대비 조건으로 1종 실패했다. 이를 원본 PNG를 별도로 디코딩한 픽셀 지문과 실제 모델 텍스처 비교로 대체하고 통과했다. 최초 로그도 보존했다.
- PC·휴대폰 크기에서 양쪽 스킨 31,608개 정점(878×36) 전체, 프레이밍, 원본 픽셀 지문 일치, 재장전·발사·살펴보기·1인칭 리그를 확인했다. 처치 코팅은 실제 WebGL 픽셀 변화로 확인했다.
- 원본 JAR 전환 검사는 로딩 중 이전 모델을 성공으로 인식하지 않도록 완료 상태까지 기다린다.
- 독립 코드 리뷰: Standards 0건, Spec 0건. 별도 검토자가 원본 JAR의 다섯 파일과 소스/패키지 바이트 일치를 확인했다.

브라우저는 소프트웨어 GPU를 사용하는 Chromium과 메모리 API 대역이다. Android 실기기, 하드웨어 GPU 성능, 운영 Redis, 실제 스토어 구매는 검증하지 않았다. 원본 파일 보존과 렌더링 검증은 Minecraft 렌더러의 조명·모션까지 동일하다는 의미는 아니다.
