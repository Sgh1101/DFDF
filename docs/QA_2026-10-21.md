## 판정 원칙

브라우저 스크립트 exit 0과 UI 감사 무진단은 다르다. `audit:ui`와 `audit:ui-home`의 JSON 항목 수를 별도로 읽는다. 실패 원인은 재현 게임 오류/테스트의 잘못된 가정/환경 제한으로 분류하고 수정 전후 로그를 보존한다.

추가한 모델 검사 초안은 내부 `buildFor`를 완성된 챔피언스 모델로 오해하고, 일부 총의 생략된 reload 기본값도 사용하지 않아 실패했다. 템플릿/원본 준비 완료와 실제 `actorReload` 경로로 검사 자체를 바로잡았다. 이것을 게임의 챔피언스 파손이나 새 탄창 고장으로 기록하지 않는다. 추가로 격리된 메모리 API의 30개 날짜에서 일일 상점 20개·주간 5개가 유지되는지 조사해 모두 확인했다. 이는 테스트 비밀값을 쓰는 표본이며 운영 상점의 미래 품목 예측이나 전 날짜 증명은 아니다.

전체 실행 중 위시리스트 검사도 한 번 실패했다. 처음 찜한 `smg|snow`가 그날 상점에 실제 판매 중이었고 두 번째 `whisper|navy`까지 찜했으므로 표시 2개가 정상이었다. 게임 집계 코드는 변경하지 않았다. 검사는 첫 찜을 판매 목록 밖에서 선택하고 서로 다른 판매 중 항목의 1→2→1 변화를 확인하도록 수정했다. 최초 실패 로그를 보존했다.

CTF의 무작위 5분 봇 전투 검사는 첫 실행 깃발 이동 0프레임, 재조사 788프레임으로 달랐고 둘 다 0득점이었다. 기본 규칙 검사는 통과했다. 회귀 검사는 상대와 무작위 능력의 영향을 분리해 양 팀 방향에서 실제 AI 이동·깃발 운반·귀환·3득점을 확인하도록 보완했다. 게임 AI를 변경하거나 모든 무작위 조합의 문제를 해결한 것이 아니다. 조합별 진행 변동성은 MAP-02 후속 작업에 남겼다. CTF 최초 실패 로그도 보존했다.
