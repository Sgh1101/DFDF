# 네온 요원

**혼자 하기 또는 방의 요원 선택 → 네온 → 전투 투입**으로 사용한다. 기존 요원 뒤에 추가해 기존 요원 식별자(`neon_agent`)와 순서를 유지한다.

네온은 **이 게임이 직접 만든 요원**이다. 외형(은발 단발과 청록 브릿지, 바이저, 남색 트랙 재킷의 전류 솔기, 빛나는 장갑, 노란 무릎 보호대, 등의 배터리), 선택 화면 초상화, 1인칭 팔과 스킬별 동작, 스킬 아이콘, 전기탄·충전·전류 벽·질주 불꽃 효과, 미끄러지기 자세를 모두 이 저장소의 코드로 그린다. 바깥에서 가져온 모델·텍스처·애니메이션·효과 코드는 쓰지 않는다. 능력의 동작과 수치만 참고 자료를 따랐다.

| 키 | 능력 | 동작 |
| --- | --- | --- |
| Q | 되튐 전격 | 0.35초 준비, 초속 38m·중력 4.8m/s², 한 번 반사. 첫 충돌과 다음 충돌(또는 반사 후 0.75초) 지점에서 각각 0.8초 뒤 반경 5m, 2.5초 뇌진탕. 벽에 가려진 적 제외. 2회, 200크레딧 |
| E | 질주 회로 | 10초간 이동 속도 1.4배. **좌클릭/모바일 사격으로 6m·0.8333초 미끄러진 뒤 질주 종료·무기 복귀**. 그 클릭은 총을 쏘지 않는다. 2킬마다 미끄러지기 충전. 재사용 30초 |
| C | 전류 통로 | 구슬이 앞으로 달리며(0.4초) 길이 25m, 높이 4m, 간격 2.4m의 전류 벽 두 개를 깐다. 지형 높이에 따라 나뉘고 4초간 양옆 시야를 막는다. 가운데 통로는 열려 있다. 1회, 300크레딧 |
| X | 과충전 | 7포인트. 20초간 손끝에서 40m 빔, 0.1초당 피해 18. 질주·미끄러지기 재충전. 궁극기 중 좌클릭 빔, 우클릭 미끄러지기 |

피해와 상태 이상은 방장이 결정한다. 질주·미끄러지기·궁극기·뇌진탕 시간은 스냅샷으로 맞춘다. 손님은 직접 피해를 주지 않는다.

코드: `js/neon-agent.js`(능력·외형·팔·전투 연결), `js/neon-effects.js`(전기 효과).

## 검증

```sh
npm run test:neon        # 질주·미끄러지기·재충전, 시야 벽, 튕기는 뇌진탕, 방장 판정 궁극기
npm run test:neon-look   # 아이콘·초상화·외형·팔 동작·효과, 실제 E/클릭 미끄러지기, 바깥 파일을 받지 않는지
npm run test:neon-online # 실제 WebRTC 방장·손님
```
