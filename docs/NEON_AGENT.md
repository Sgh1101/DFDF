# 전광 요원

**혼자 하기 또는 방의 요원 선택 → 전광 → 전투 투입**으로 사용한다. 기존 요원 뒤에 추가해 기존 요원 식별자(`neon_agent`)와 순서를 유지한다. 예전 표시 이름은 "네온"이었고, 이름만 바꿨다(식별자·저장 기록은 그대로).

전광은 **이 게임이 직접 만든 요원**이다. 2026-11-07부터 네 능력의 동작과 수치도 이 게임의 것이다(붙어서 두 번 터지는 전극탄, 앞을 가로막는 장막 하나, 자체 질주·빔 수치). 외형(은발 단발과 청록 브릿지, 바이저, 남색 트랙 재킷의 전류 솔기, 빛나는 장갑, 노란 무릎 보호대, 등의 배터리), 선택 화면 초상화, 1인칭 팔과 스킬별 동작, 스킬 아이콘, 전기탄·충전·전류 벽·질주 불꽃 효과, 미끄러지기 자세를 모두 이 저장소의 코드로 그린다. 바깥에서 가져온 모델·텍스처·애니메이션·효과 코드는 쓰지 않는다. 능력의 동작과 수치만 참고 자료를 따랐다.

| 키 | 능력 | 동작 |
| --- | --- | --- |
| Q | 이중 전격 | 0.3초 준비, 초속 34m·중력 6m/s². 처음 닿은 곳에 붙어 0.5초 뒤, 다시 1.2초 뒤 두 번 반경 4m에 터져 각각 1초 뇌진탕. 튕기지 않는다. 벽 너머는 맞지 않는다 |
| E | 질주 회로 | 8초간 이동 속도 1.3배. **좌클릭/모바일 사격으로 5m·0.7초 미끄러진 뒤 질주 종료·무기 복귀**. 그 클릭은 총을 쏘지 않는다. 처치할 때마다 미끄러지기 재충전 |
| C | 전류 장막 | 구슬이 앞으로 9m 달린 뒤 그 자리에 폭 14m, 높이 3.5m 장막을 가로로 세운다. 지형 높이에 따라 나뉘고 6초간 앞쪽 시야를 막는다 |
| X | 과충전 | 8포인트. 14초간 손끝에서 32m 빔, 0.12초당 피해 21. 질주·미끄러지기 재충전. 궁극기 중 좌클릭 빔, 우클릭 미끄러지기 |

피해와 상태 이상은 방장이 결정한다. 질주·미끄러지기·궁극기·뇌진탕 시간은 스냅샷으로 맞춘다. 손님은 직접 피해를 주지 않는다.

코드: `js/neon-agent.js`(능력·외형·팔·전투 연결), `js/neon-effects.js`(전기 효과).

## 검증

```sh
npm run test:neon        # 질주·미끄러지기·재충전, 시야 벽, 튕기는 뇌진탕, 방장 판정 궁극기
npm run test:neon-look   # 아이콘·초상화·외형·팔 동작·효과, 실제 E/클릭 미끄러지기, 바깥 파일을 받지 않는지
npm run test:neon-online # 실제 WebRTC 방장·손님
```
