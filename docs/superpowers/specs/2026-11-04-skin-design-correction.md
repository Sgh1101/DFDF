# 챔스 자체 디자인과 RGX 나비칼 복구

사용자는 챔스를 원본 파일 그대로 넣는 변경을 거부하고, 원본의 분위기를 참고한 자체 디자인을 다시 요구했다. 칼은 RGX 나비칼만 제공된 원본으로 유지하고 나머지는 자체 제작하며 기존 모션을 보존한다. 이번 ‘해’는 이 교정 작업의 진행 승인이다. 별도 main 병합 승인은 완료 후 받는다.

## 기존 승인과 구현 방식

챔스는 이미 승인된 진홍/금색 공격형과 상아/금색 수비형 시안을 재사용한다. 현재 남아 있는 `gun.js`·`gun-paint.js` 생성기를 기본 빌드로 연결하고, JAR 총 JSON·텍스처를 그대로 복사하는 경로를 제거한다. 단순 색상 변경이나 원본 전체 모델 사용, 장착 시스템을 바꾸는 외부 GLB 도입은 선택하지 않는다. 원본은 참고 자료이며 배포 총 자산은 생성기로 만든다.

RGX는 사용자가 제공한 Knife Pack의 `future_butterfly`(영문 표기 RGX 11z Firefly)만 읽는다. 다른 외부 총이나 칼 팩은 다시 넣지 않는다. 기존 `butterfly` 스킨 보유·장착 키를 유지하면서 실제 모델·텍스처와 원본 모션을 표시하고, 과거 RGX 보유 기록이 있다면 손실 없이 이전할 수 있는지 확인한다. 제공된 데이터·이미지만 읽고 실행 코드는 로드하지 않는다.

나머지 기본/접이식/탄토/쿠크리/카람빗/총검/거트/보위/쿠나이/스틸레토는 칼날·그립·장식이 구분되는 자체 형상으로 재제작한다. 애니메이션에 쓰이는 피벗·손 위치·스케일·타이밍·자세히 보기와 공격 모션은 보존한다. 새 색만 덧씌운 것을 재제작으로 기록하지 않는다.

## 유지할 동작

- 챔스는 팬텀(`scout`)에만 장착한다. 보유·장착·재화·가격·확률을 변경하지 않는다.
- 처치 물결·배너·사운드·자체 작곡·8초 마무리와 기존 용/뱀 움직임은 계속 동작해야 한다.
- 별도 미완성 worktree는 수정하지 않는다. 승인된 네트워크 수정 PR #118의 배포는 별도로 마무리한다.
- 취소한 보안 검사나 호스팅 요금제 변경은 이번 작업에 포함하지 않는다.

## 검증

생성물의 자체 소스·결정성, 원본 복사 방지, 두 변형과 처치 물결의 색 정합성, 칼 형상과 기존 모션 계약을 단위 검사한다. UI는 실제 미리보기·장착·자세히 보기 경로를 먼저 탐색하고 검사한다. 실제 렌더러의 PC/휴대폰 화면에서 모양·스케일·손 위치를 비교하고, 음원·마무리·보유 이전·네트워크 회귀를 확인한다. 에뮬레이션과 실제 기기/회선 검증을 구분한다.
