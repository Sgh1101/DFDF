# DFDF 전체 시각·음악 개편 설계

사용자 요청: 챔피언스 디자인과 음악 전면 개선, 마크×발로 맵을 실제 지역처럼 수정, 보안 검사, 글꼴 수정, 기존 카람빗·나비칼을 자체 모델/디자인으로 재제작하되 모션 유지. 전체 계획을 세우고 진행한다.

## 선택한 방식

기존 Three.js 렌더러와 큐브/프로파일 모델·합성 음악 생성기를 유지한다. 외부 완성 모델·맵·곡을 추가하는 방식은 기존 장착·모션·모바일 최적화와 충돌하므로 사용하지 않는다. 작은 독립 변경으로 커밋하고 마지막에 통합한다. 이 선택은 에이전트의 구현 판단이며 사용자가 특정 라이브러리를 지정한 것으로 기록하지 않는다.

- 챔피언스 총은 별도 `codex/champions-concept-v2`에서 작업 중인 승인된 시안(공격 진홍·금색, 수비 상아·금색)을 먼저 검토한다. 진행 중인 worktree는 직접 수정하지 않고 완료된 커밋을 통합한다. 총구·리그·장착·보유·가격·확률·8초 마무리 조건은 보존한다. 배너·용/뱀 표현은 같은 시각 언어로 정리한다.
- 킬 1~5, 미리보기, 마무리 음악은 새 자체 작곡으로 바꾼다. 현재 합성 악기와 이벤트 키를 유지하며 이전 멜로디를 단순 변조한 것으로 끝내지 않는다. 음량·피크·음소거·중지·반복·재개를 검증한다. 원본 게임의 곡을 복제하지 않는다.
- 하늘섬(`ascent_trial`, 사용자가 말한 마크×발로)은 블록 스타일을 유지한 자체 마을로 만든다. 중앙 진입도로·보도·주거/상가 블록·광장·골목·옥상/계단·가로등과 생활 소품으로 공간을 구분한다. A/B 거점의 동선·시야·엄폐를 함께 설계하고 내부와 출입구를 실제 충돌에 맞춘다. 기존 schematic은 사용하지 않는다. 모바일은 같은 충돌을 쓰고 세부 표현을 줄인다.
- 본문은 Noto Sans KR 고딕체, 주요 한글 제목은 Black Han Sans, 중요 수치는 Noto Sans KR의 굵기·고정폭 숫자를 사용한다. 기존 Orbitron 브랜드 표현은 필요한 곳만 유지한다. 읽기 어려운 장식 글꼴과 중복 로드를 줄이고 모바일 줄바꿈·터치·대비를 확인한다.
- 카람빗은 짙은 금속과 구리색 결합부의 곡선 칼날·링·그립, 나비칼은 은색 칼날과 청록색 프레임·손잡이 창을 가진 자체 디자인으로 만든다. 현재 `karambit`/`butterfly` 스킨 ID·보유 정보는 유지한다. `spin`, `hA`, `hB` 부품과 피벗·손 위치·스케일·모션 곡선·지속 시간은 그대로 둔다.
- 보안은 고정된 기반 커밋 `45ce6f3`를 별도 읽기 전용 대상으로 표준 검사한다. 계정·운영자·Redis 재화/보상·문의/채팅·방/P2P 신뢰 경계를 검토한다. 최종 변경의 새 입력/로딩 경계도 통합 검토한다. 후보를 검증 결과와 구분하고 자격 증명을 노출하거나 운영 데이터를 바꾸지 않는다.

## 승인과 경계

이번 요청은 챔피언스 디자인/음악 변경에 대한 명시적 승인이다. 이전의 ‘챔피언스 변경 전 승인’ 규칙을 충족하되, 재화·보유·확률·마무리 조건을 변경하는 승인으로 확대하지 않는다. 칼 모션 보존은 필수다. 다른 worktree의 미완성 연습장·시안은 임의로 덮어쓰거나 같이 배포하지 않는다.

광고 활성화는 이번 시각 개편과 별개다. 계정 승인·인증 CMP·권리 확인 전에는 광고가 꺼진 상태를 유지한다. 배포 요청은 유지하며 main 병합은 별도로 하지 않는다. Vercel 운영 승격은 현재 사용자 재인증을 기다리고 있으므로 실제 완료 전 배포됐다고 말하지 않는다.

## 검증과 시각적 판정

실제 렌더러에서 두 총·두 칼의 미리보기/1인칭/모션을 확인하고 가려짐·분리 부품·비정상 스케일을 검사한다. 단순 빌드 성공을 시각 품질 검증으로 대체하지 않는다. 칼의 기존 모션 샘플과 피벗을 비교하고, 음악은 결정성·길이·음정 범위·피크 및 실제 재생을 검사한다. 맵은 양 팀 스폰·A/B까지 실제 몸체 이동·벽/총알·천장·능력 바닥·그래픽 전환·정리를 검사한다. 모바일 에뮬레이션과 실기기는 구분한다. 맵 분위기와 경쟁 밸런스의 사람 평가가 남는 한계도 기록한다.
