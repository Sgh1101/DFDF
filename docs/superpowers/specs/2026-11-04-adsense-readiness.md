# AdSense 심사 준비 개선

사용자 요청: 13fps.xyz를 현재 AdSense 기준에 맞게 개선한다. 사이트는 심사 중이며 실제 광고 활성화·Google 계정의 승인/성인 명의/CMP 인증을 코드로 대신하지 않는다.

## 결정한 범위

- 비로그인 첫 화면에 실제 게임 이미지·게임 방식·가이드 진입을 먼저 보여 준다. 기존 로그인/가입·게스트·초대 링크·로그인 사용자 대시보드는 유지한다. 로그인 유도를 광고 클릭과 연결하지 않는다.
- 기존 광고 기본 OFF와 안내 문서 6개 URL 허용 목록을 유지한다. 광고 준비 점검은 계정 심사, 성인 신청자 확인, 대상 연령, 실제 CMP/지역별 동의, 현재 자산 사용권을 각각 구분한다. 로컬 선호 저장은 동의 인증이 아니다.
- 외부 사용권이 미확인인 황혼 지구 구조와 SGH 나비칼의 유지한 뼈대/모션/음원을 명시적으로 차단 사유로 기록한다. 두 묶음의 파일 지문을 고정하고 변경 시 검토를 무효화한다. 단순 rightsReviewed=true만으로 활성화하지 못한다.
- 출처·개인정보·무료 재화/광고 보상 정책을 실제 기능과 일치시킨다. 운영자에게 필요한 실제 계정 작업과 허가 증빙 범위를 기록한다.
- 챔스 및 다른 PR/작업 폴더를 건드리지 않는다. 맵 구조와 나비칼 모션 보존은 직전 사용자 요청이므로, 허가 답변 없이 임의로 다른 작품으로 교체하지 않는다. 미확인 자료를 허가된 것으로 표시하지 않는다.

## 완료 기준

공개 첫 화면은 JS 없이도 게임 소개와 문서 링크를 제공하고, 360px·375px·1280px에서 겹침/넘침 없이 조작된다. 기존 로그인/게스트 경로가 동작한다. 광고 점검기는 실제 미충족 항목을 출력하며 활성화 요구 시 실패한다. 동의 미확인/오류·미성년 처리 미검토·현재 파일과 다른 권리 기록·게임/로그인/상점 페이지는 광고 불허다. 실제 광고 SDK는 추가하지 않는다.

승인 보장, 법률 판정, 실제 Android/WAN/광고 송출/실결제 검증으로 표현하지 않는다. 새 작업의 main 병합·운영 배포는 아직 승인되지 않았다.
