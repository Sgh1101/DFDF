# 챔스 팬텀 입체 모델 재설계

사용자는 평면적이고 뼈대처럼 보이는 현재 총을 실제 소총 같은 입체 형태로 다시 만들라고 요청했다. 앞선 '알아서 판단해서 진행' 지시에 따라 구현 방식은 자체 결정하고, 완성된 실제 렌더로 검토받는다. 이 지시는 챔스 모델 수정 승인이다. 이번 변경의 main 병합은 별도 승인을 받는다.

단순히 폭만 늘리면 직각 상자와 얇은 금색 선이 그대로 남는다. 외부 총 모델을 가져오면 자체 디자인 요구에 맞지 않는다. 따라서 기존 본 구조 안에서 자체 베벨 박스와 원형/속 빈 원통을 생성해 닫힌 몸통, 두꺼운 개머리판, 곡선 탄창, 둥근 소음기를 구성한다. 외부 에셋과 새 라이브러리는 추가하지 않는다.

진홍/금색 공격형, 상아/금색 수비형은 유지한다. 큰 금색 판과 선 장식을 줄이고, 상·하부 몸통, 탄창 삽입부, 방아쇠울, 고무 그립, 배출구, 볼트, 통풍구와 조준기를 구분한다. 금속과 코팅·고무가 다르게 빛나도록 자체 표면 맵을 만든다. 기존 팔레트와 처치 물결은 유지한다.

모델은 512px 아틀라스와 기존 17개 본/피벗을 사용한다. 총구는 [41.25,0,0]을 유지한다. 부품 240개 이하, 실제 렌더 정점 15000개 이하. 미리보기뿐 아니라 1인칭·장전·발사·떨어진 총·다른 플레이어 표시에도 같은 모델을 쓴다. 기존 모션과 재화·보유·장착 대상, 오디오·배너·마무리는 바꾸지 않는다.

새 솔리드 메시는 DFDF 표시가 있는 부품에만 적용한다. 일반 Bedrock 큐브와 원본 RGX 모델은 기존 정점/UV/본을 보존한다. 베벨·원통의 UV는 기존 아틀라스 면에 투영하고, 페인터는 각 삼각형의 부품/면 메타데이터를 사용한다. 거친 정도/금속성 표면 맵은 sRGB 색 변환 없이 읽는다.

단위 검사로 표면 방향·UV 범위·원통 구멍·정점 예산·기존 큐브 불변·결정적 생성을 검증한다. 브라우저에서 두 변형의 비스듬한 화면·위쪽/앞쪽·실제 1인칭, PC/휴대폰 크기, 재접속 캐시, 장전/처치 물결과 RGX 회귀를 확인한다. 실기기나 실결제를 확인했다고 표현하지 않는다.
