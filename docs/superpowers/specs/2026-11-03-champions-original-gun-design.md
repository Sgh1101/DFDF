# 챔피언스 원본 총 외형 복원

사용자가 선택한 범위는 처음 제공한 `ChampionsPhantom2026-0.1.0.jar`의 총 모양·비율·색상이다. 해당 총 JSON과 공격·수비 기본/발광 텍스처 다섯 파일을 그대로 빌드 입력으로 보관하고 기본 패키지에 바이트까지 동일하게 포함한다. 원본의 33개 뼈대, 878개 큐브, 피벗·회전·512×512 UV를 보존한다.

현재 별도 제작 모델(17개 뼈대·132개 큐브)과 원본 사이의 차이가 확인됐다. 원본 파일 직접 패키징은 요청한 기준을 해시로 확인할 수 있다. 장착 대상 팬텀(scout), 보유·구매·코인·성능 계약을 유지한다. 음악·마무리·배너와 현재 게임 모션은 이번 총 외형 수정 범위에 포함하지 않는다. 원본 색에 맞는 처치 물결 판정을 사용한다.

빌드는 다섯 파일의 크기·SHA-256을 검증한다. Java 코드는 실행하지 않는다. 출처 문서는 총 원본과 나머지 자체 생성 자산을 구분한다. 뼈대별 메시 병합을 유지하고, PC·휴대폰 전체 프레이밍과 1인칭 장착·장전·발사·처치 물결을 검사한다. 팩 전환 검사는 완성된 새 모델을 기다려 이전 모델을 성공으로 오인하지 않아야 한다.
