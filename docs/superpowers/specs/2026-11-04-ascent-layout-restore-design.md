# 황혼 지구: 원본 구조 복원과 외형 변경

사용자의 최신 요청은 맵 이름/외형을 바꾸고 공간을 넓히되 실제 어센트의 구조를 유지하는 것이다. 현재 `neighborhood-2`는 원본을 자체 마을로 교체했으므로 이 요청에 맞지 않는다. 예전 독립 마을 설계는 이번 지시로 대체한다.

제공된 `ascent-final2021.schematic`를 기준으로 지형/엄폐/높이/연결을 복원한다. 원본 SHA-256은 b987d994b5aa01e0b614b5e7d92a4b8f41f7cf6ecab1daddd5ba3fc4cf1b9c28이며, crop [55,12,16], dimensions [206,115,223], 높이 scale1.25를 보존한다. 캐릭터 폭을 확인한 결과 가로·세로는 horizontalScale1.75로 넓혀 약361×390m로 정했다. 현재120×140m 마을보다 크다. 추가로 계단 높이를 키우거나 새 연결로를 만들지 않는다. 비교 기준은 제공된 2021 schematic이며, 최신 공식 게임의 모든 도어 기믹/패치가 같다고 주장하지 않는다. 공식 어센트 개요도 참고: https://playvalorant.com/en-gb/maps/.

이름은 가칭 황혼 지구 / Dusk District. 기존 ID `ascent_trial`은 보존한다. Claude의 자체 블록 팔레트/투명 마스크를 유지하며 자체 색상·재질/조명으로 외관을 구분한다. 원본 Minecraft/Riot 텍스처는 추가하지 않는다. 원본 schematic은 실행 코드가 아니라 지형 데이터로만 읽고, 변환된 지형과 출처 해시를 배포한다.

핵심은 충돌/원본 좌표 보존이다. 두 스폰, A/B, 미드와 주요 연결 지점을 원본 좌표로 기록한다. 실제 몸체가 통과 가능한 길찾기와 설치 지점·장판 높이를 검사한다. 모바일은 같은 충돌을 쓰며 화면용 면만 줄인다. 현재 원본 변환은302566쿼드/44380충돌, 경량은166330쿼드이므로 실제 성능을 확인하고 한계를 기록한다.

다시 `build:original-maps`를 실행해도 자체 마을로 되돌아가지 않도록 원본 입력과 재생성 경로를 고정한다. 현재 스킨 PR #126, 요원/손 모션, 운영자 권한, 기존 다른 맵은 이번 변경에 포함하지 않는다. 새 모델/맵 각각의 main 병합은 별도 사용자 승인을 적용한다.

### 구현 중 확인에 따른 축척/좌표 정정

캐릭터 지름(PR×2)1.5m가 원본 한 블록 통로1.25m보다 넓고 단층 내비게이션이 다리 아래 기초 바닥을 골랐다. 원본 X/Z 배치 자체는 그대로 두되 horizontalScale1.75로 넓혀 외곽360.5×390.25m로 정했다. 높이 scale1.25(반 계단.625m)는 유지한다. 다층 그래프/블록 중심 격자/실제 몸체 판정을 사용한다. 필수 구역은 원본 평면과 실제 바닥에 맞춰 명시적 높이와 함께 고정한다. 공격[175,55,7.5], 수비[155,185,11.25], A[95,145,13.75], B[225,148,5], 미드[160,120,10]. 자동 좌표 이동은0m. 바이너리 원본/충돌 해시는 그대로다. 위 초기258×279m 크기 결정은 이 검증 결과로 대체한다.
