코드 검증 기준은394603d, 승인 병합된 main bcdec21 위다. Claude#127의 SGH나비칼을 유지하며#126/#128의 미승인 총/스킨 변경은 포함하지 않는다. 독립 리뷰는 남은 지적 없이 승인됐다. 원본/좌표/재생성 설명은 [ASCENT_TRIAL.md](../../../../docs/ASCENT_TRIAL.md)를 따른다.

- 로컬 단위517통과·2선택Redis검사제외. GitHub [41805604486](https://github.com/Sgh1101/DFDF/actions/runs/41805604486)에서는 실제Redis 포함519개 전부 통과·제외0, 브라우저3샤드 전부 통과.
- 같은 코드를 고정한 로컬 브라우저13종 전부 통과, 재시도0·실행 중 소스 변경0. 목록과 시간은 verification.json. 단순 빌드/합성 구매를 실기기·실결제로 표시하지 않는다.
- routes.json: 공격/수비→A/B 네 경로를 실제 몸체 이동으로 끝까지 통과. 원본 필수 좌표 이동0m, 층별 이동을 구분한다.
- objectives.json: A/B 수동 설치·폭탄/떨어뜨림/폭발 높이, A아래층 설치/해제 차단과 정상 해제, 같은 X/Z의13.75→18.75m 목표 재탐색과 실제 봇 추적, 전체 지형이 미리보기 안에 들어가는 것을 확인한다. 로컬 WebRTC 검사에서 양쪽 폭탄 높이와 방장이 아래층일 때 참가자의 위층 순간이동도 확인했다.
- mobile.json: 동일 고정 시점의 지형 삼각형339022/573832(약41% 감소), 호출97/167(약42% 감소), 지형 GPU버퍼36592600/66564520(약45% 감소). 모바일은852×393픽셀·배율1을 유지한다. 충돌·그래프·배우는 동일하다. 이 수치를 실제휴대폰 FPS 개선율로 해석하지 않는다.
- overview.webp는 실제 게임 렌더러로 생성한 현재 전체 미리보기다. 자체 타일/색상/조명과 원본 구조를 구분해 기록했다.

실제Android, WAN, 실제스토어 결제는 검증하지 않았다. 이전 단순 마을보다 지형 파일과 메모리는 크다. 원본의 최신 공식 도어/패치 전체가 아니라 사용자가 제공한2021구조를 기준으로 복원했다. main 병합 및 운영 배포는 별도 사용자 승인 전 수행하지 않았다.
