# AdSense 심사 준비 개선 검증

시작: 2026-11-04, 최종 로컬 검증: 2026-11-05 KST. 제품 코드 `849e366`은 승인된 최신 main `165caf3`의 Claude#128/#129를 포함한다. 후속 커밋은 문서/증거와 브라우저 검사 언어 환경을 보완하며 게임·홈·광고 정책 런타임은 그대로다. [PR#131](https://github.com/Sgh1101/DFDF/pull/131)은 별도 병합 승인 대기다.

## 실제 수정

로그인 전 홈에 실제 자체 포구 맵 이미지·게임 방식·조작/팀 역할/초대 안내와 가이드 링크를 먼저 보여 준다. 기본 로그인/가입·게스트·초대 URL·계정 대시보드는 유지한다. 정적 소개와 가이드는 JS 없이도 읽힌다. 소개 문서의 게스트/랭크 조건과 기기 성능 설명을 실제 기능에 맞췄다.

광고는 OFF이며 광고 SDK·슬롯을 추가하지 않았다. `monetization-review.json`과 광고 정책은 실제 계정 심사·성인 신청자·대상 연령·지역/CMP·전체 자산 검토를 분리하고, 황혼 지구4파일과 SGH나비칼12파일의 현재 지문을 검사한다. 실제로 Claude#129 manifest 변경을 감지해 차단했고, 그 지문만 새로 기록한 뒤에도 사용권 미확인은 유지했다. `--require-ready`는 현재 종료코드1이다.

## 남은 외부 확인

사이트는 사용자 답변상 AdSense 심사 중이다. 실제 승인·신청인 신원/성인 여부, 대상 연령과 지역별 처리, 실제 CMP 설정/인증/거절/철회 검증은 코드로 완료했다고 표시하지 않았다. 미확인 두 자산 묶음의 웹 게임 사용·수정·재배포·광고 수익화 권한 및 전체 자산 검토도 남아 있다. 광고 OFF는 공개 자료의 사용권을 해결하지 않는다. Google 승인을 보장하지 않는다.

## 위임받아 내린 판단

1. 별도 작업 공간에서 직접 구현하고 마지막에 독립 리뷰를 받았다. 비용: 구현 중 독립 검토가 없었으며 마지막 리뷰와 회귀 검사로 보완했다.
2. 내장 worktree 도구가 중첩 repo 경로를 허용하지 않아 sibling Git worktree를 만들었다. 비용: 앱의 관리형 worktree 목록에 등록되지 않는다. Git 브랜치/경로와 기존 작업은 보존했다.
3. 원본 맵 구조·나비칼 모션 유지 요청과 권리 확인이 충돌하므로 답변 없이 자동 교체/삭제하지 않았다. 비용: 해당 권리 문제는 여전히 해결 전이며 광고 활성화를 막는다.
4. 독립 리뷰가 외부 계정·사용권 증거를 판정할 수 없다는 제한을 유지했다. 비용: 이 PR을 전체 AdSense 적합성 완료로 해석할 수 없다.
5. 이미 승인된 upstream의 총/챔스 기능은 그대로 통합하고 우리 diff가 추가로 건드리지 않았음을 확인했다. 비용: upstream 전체 기능을 새로 전수 심사한 것은 아니며 관련 통합 회귀 검사 범위만 입증한다.

보류한 경미한 코드 지적은 없다. 이전 Codex#126은 현재 main의 Claude#128과 겹치므로 별도 정리 대상으로 남기며 이 PR에 합치지 않는다.

## CI 언어 환경 차이 수정

GitHub의 en-US 시작에서 새 public-entry 검사가 한국어 시작을 가정해 언어 전환 결과를 반대로 기대했다. 로컬 브라우저의 locale을 en-US로 명시해 같은 실패를 재현한 뒤, en-US/ko-KR을 크기별로 고정하고 초기 언어·양방향 전환·메뉴 재열기를 명시적으로 확인하도록 수정했다. 같은 네 화면과 JS OFF 경로가 통과했고 단위521통과/선택Redis2제외를 다시 확인했다. 게임/홈 런타임 변경은 없으며 이 수정의 최종 CI는 PR Checks에서 확인한다.
