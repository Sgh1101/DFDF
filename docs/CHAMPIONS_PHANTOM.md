# 챔피언스 팬텀 연결

팬텀에 `champions_atk`(공격: 연회색 개머리판·검은 몸체·금색), `champions_def`(수비: 검은 개머리판·회색 상부·금색) 초월 스킨을 추가했다. 총 스킨 창 위쪽 **챔피언스** 탭 안에 전용 구매 화면이 있다. 그 안에서 색상, 발사음, 킬 배너·소리, 마무리, 살펴보기, 재장전을 미리 볼 수 있다. 보유한 색상을 누르면 팬텀에 장착되며 기존 계정 저장과 방의 스킨 동기화를 사용한다. 미보유 색상은 미리보기만 가능하다. 초월 코인 700개로 구매하거나 기존 **뽑기** 탭에서 다른 스킨과 함께 0.00000000000000001% 확률로 획득한다. 별도 챔피언스 뽑기는 만들지 않는다. 관리자 지급 항목은 `scout|champions_atk`, `scout|champions_def`다.

피해량·탄창·연사·판정은 팬텀 그대로다. 실제 마무리는 기존 규칙에 따라 일반전에서 마지막 적을 총으로 처치했을 때 한 라운드에 한 번 재생된다. 수류탄·능력·환경 피해, 다른 모드에는 적용하지 않는다. 모바일의 낮은 품질 설정과 동작 줄이기 설정을 따른다. 무기 살펴보기는 기존 Y 키와 터치 버튼을 사용한다. 재장전·꺼내기·사격은 기존 게임 손 모션을 유지하고 탄창·장전 손잡이 뼈대를 추가로 움직인다.

## 초월 등급과 초월 코인

무기고의 별도 **스킨 등급표**와 내 스킨 필터는 일반 → 희귀 → 영웅 → 전설 → **초월(5단계)** 순서다. 팬텀 공격·수비만 초월이며 기존 전설은 그대로다. 공유 데이터 `js/skin-tiers.js`를 게임·API·관리자 화면이 사용한다.

경기 완료 보상 기준(기존 경기 확인표와 60초 이상 경과)을 충족하면 승리·패배·무승부 모두 초월 코인 **1개**를 받는다. 연습/사격장·중도 이탈은 완료 보상을 만들지 않는다. 신규 코인 잔액은 0이며 기존 경기 수로 소급 지급하지 않는다. 골드와 별도로 계정/게스트 기록에 저장하고, 경기 확인표 소비·잔액 증가·재시도 영수증을 한 번에 저장해 재전송으로 중복 지급하지 않는다. 홈페이지와 초월 상점에서 잔액을 본다.

**공격/수비 스킨은 각각 700코인**이다. 초월 상점에서 두 번 눌러 구매를 확정하며, 서버는 가격을 700으로 고정한다. 골드는 사용하지 않는다. 부족한 잔액, 중복 보유, 동시 구매는 잔액을 음수로 만들지 않는다. 일일/주간 골드 상점에는 나오지 않으며 기존 관리자 지급 기능은 유지한다.

골드 뽑기에서는 초월 등급을 정확히 **0.00000000000000001% (1 / 10¹⁹)**로 별도 추첨한다. 암호학적 64비트 난수를 BigInt 정수로 읽고 범위 밖 표본을 다시 뽑아 나머지 연산의 편향을 없앤다. 보통 등급의 가중치와 독립적이며, 전설까지 전부 모았을 때의 보정이 초월로 자동 승급하지 않는다. 보유한 초월 스킨은 중복 지급하지 않는다. 일반 뽑기 가능 품목이 모두 소진되면 기존처럼 더 뽑을 수 없다.

## 자체 총 디자인과 DFDF 연출 (2026-11-04)

사용자는 JAR 원본 파일 복사가 아닌, 원본을 참고한 자체 제작을 요청했다고 정정했다. 2026-11-04 재요청에 따라 총은 PR #115에서 확인한 원본 외형(둥근 갈고리형 통짜 개머리판, 각진 그립·탄창, 계단형 총열 덮개, 각진 총구)을 시각 참고로만 삼아 DFDF가 직접 다시 모델링했다. 원본의 큐브 목록·UV·텍스처는 읽거나 변환하지 않았고 렌더 화면에서 눈으로 잰 비율만 맞췄다. `npm run build:champions-phantom`은 자체 형상·텍스처와 나머지 연출을 생성하며 원본 복사 경로는 없다. 비교용 원본 지문만 `docs/superpowers/records/2026-11-04-champions-reference-hashes.json`에 남긴다. 팬텀(`scout`) 장착·보유·구매·코인·음악·마무리·배너 계약은 유지한다.

- **총** (`gun.js`, `gun-paint.js`): 손으로 배치한 약 110개 큐브(기울인 상자로 개머리판 둥근 뒤꿈치·절개부, 그립·탄창 각도, 덮개 단차를 표현)와 512×512 공격/수비 기본·발광 아틀라스. 색은 역할별로 칠한다 — `frame`(개머리판·그립·탄창 앞면·총구: 공격 연회색/수비 검정), `body`(상부 리시버·덮개·총열 덮개: 공격 검정/수비 연회색, 처치 코팅 대상), `lower`(하부 리시버: 공격 검붉은색/수비 암갈색), 금색 테두리·장식, 흰색 붓질 발광 무늬(공격은 붉은 테두리). 기존 총구(`muzzle_pos` 41.25)·장착·애니메이션 뼈대와 피벗을 유지하고 런타임에서는 뼈대별 메시 병합과 팬텀 배치를 사용한다.
- **움직임** (`animation.js`): 재장전(탄창 분리→새 탄창→장전 손잡이), 꺼내기(장전 손잡이), 사격(방아쇠·노리쇠), 살펴보기 루프를 직접 키프레임으로 만든다. 게임은 이전처럼 이 뼈대들만 움직이고 손·카메라 위치는 게임이 정한다.
- **마무리 용·뱀** (`creatures.js`): 스플라인을 따라 놓은 큐브 마디로 만든 긴 용(공격: 검붉은색, 수비: 2.8초 뒤 상아색)과 똬리 튼 뱀(공격: 크림색 무늬, 수비: 붉은색·검은 무늬, 머리 장식이 다름). 장면 코드의 고정 좌표(눈 빛, 모래시계, 두 조각상)에 맞춰 배치했다.
- **효과·배너** (`fx.js`): 리본·별·소용돌이·고리·빛줄기·불씨·다이아몬드·밤하늘, 킬 수에 따라 장식이 늘어나는 다이아몬드 배너 테두리와 진영별 엠블럼, 총 처치 코팅 그림과 불꽃 스프라이트.
- **소리** (`audio.js`, `js/phantom-audio.js`): 녹음 파일이 없다. 킥·스네어·하이햇·베이스·기타·하프·차임·벨·플루트 9개 악기를 브라우저가 숫자 레시피로 합성한다. 1~5킬 연주(킬마다 화음이 올라가고 5킬은 2.6초 팡파르), 살펴보기 그루브(0.6~10.2초 반복), 마무리 테마(0~19.2초, 3.03초부터 재생)는 DFDF의 새 편곡이다. 발사·처치·헤드샷·마무리 효과음은 기존 DFDF 합성음 그대로다.

manifest의 크기·SHA-256을 확인하고 텍스처를 디코딩한 뒤 적용하며, 실패하면 안내와 재시도 버튼을 보여준다. 자산 URL에 파일 해시를 붙여 이전 서비스 워커의 다른 형상·텍스처와 섞이지 않게 한다. 일반 화면의 JAR 불러오기와 예전 로컬 원본 자동 적용은 제거한다. **디자인 다시 불러오기**는 자체 패키지를 다시 적용하며 과거 브라우저 원본 캐시를 정리한다. 처치 코팅 색 판정은 자체 아틀라스와 같은 `PALETTES`를 사용한다.

## 용·뱀 마무리와 8초 전환

처치 후 2.66초에 모델을 표시하고 2.8초에 수비형 용의 색을 바꾼다. 7~8초에 1초 페이드 후 전환한다. 모델 크기는 필요하면 확대해 **플레이어 키의 최소 5배**를 보장한다. 자체 용·뱀 관절과 턱은 기존 절대 시간 모션으로 움직이고 주변 리본·별·소용돌이·고리·빛줄기·파편·점멸·번개·불씨가 이어진다. 처치 이벤트의 tick·위치로 호스트/게스트 배치를 일치시킨다. 동작 줄이기에서는 전체 마무리 시각 효과를 재생하지 않는다.

일반전에서 챔피언스 마지막 처치가 인정되면 **처치 시각부터 8초 후** 다음 라운드를 시작한다. 승리 점수에 도달한 경우에는 8초 후 경기 결과로 이동한다. 기존 전설 `champion`도 같은 8초를 사용하고 다른 스킨의 기존 라운드 대기 시간은 유지한다. 호스트가 남은 시간을 스냅샷에 보내며 다음 라운드·방 나가기·경기 종료 시 마무리와 예약된 라운드 전환을 정리한다.

팬텀 처치에는 일반 처치·헤드샷·멀티킬 합성 멜로디가 겹치지 않는다. 미리보기 버튼을 다시 누르면 1~5킬 연주를 순환한다. 공유 음량·효과음 설정은 그대로 적용한다.

정찰 소총과 팬텀은 표시 이름을 서로 바꾼다. 내부 ID는 carbine=정찰 소총, scout=팬텀이며 모델·성능은 유지한다. 기존 돌격소총(rifle)·카빈(carbine)에 있던 챔피언스 구매분은 첫 계정 조회/저장 때 팬텀(scout)으로 옮긴다. 코인·골드를 재청구하지 않고 중복 소유를 합치며, 팬텀에 다른 스킨을 장착해 뒀다면 그 선택을 유지한다. 장착 변경의 저장 시각을 갱신해 오래된 돌격소총 설정이 되살아나지 않게 한다.

브라우저에 더 최신인 돌격소총·카빈 챔피언스 장착 캐시가 있어도 먼저 팬텀으로 옮긴 뒤 계정과 동기화한다. 현재 팬텀의 다른 선택은 유지하고, 최근 뽑기 기록의 챔피언스 항목도 팬텀으로 표시한다. `npm run test:phantom-carbine`은 기존 계정/로컬 캐시 이관·무료 유지·상점 장착·팬텀의 챔피언스 총 모델·돌격소총 기본 모델을 확인한다.

`DFDF_PLAYWRIGHT_MODULE`, `CHROME_BIN`, `DFDF_BASE_URL`, `SHOT_DIR`는 기존 브라우저 테스트와 같다. 자체 모델 자동 표시/모든 큐브 표시/512×512 텍스처/로딩 실패와 재시도/별도 구매 탭/등급표/초월 필터/정확한 확률 표시/경기 보상 반영/700코인 구매/소유권/장착/배너/마무리 정리/반응형을 검사한다. `test:champions-default`는 과거 브라우저 원본 캐시가 자체 디자인을 덮어쓰지 않는지 확인한다. 스크린샷은 git에서 제외되는 `test-results`에 저장된다. 테스트 구매/관리자 지급은 메모리 API 도구를 사용하며 실제 계정이나 결제를 변경하지 않는다.

브랜치와 PR은 검토용이다. 사용자 승인 전 병합하거나 운영 배포하지 않는다.

`test:champions-finish`는 실제 상점 버튼과 일반전 마지막 처치를 사용해 전체 도형 수·공격/수비 조합·카메라 표시 범위·최소 5배 크기·7.999초 유지·8초 전환·방 나가기 취소를 검사한다. `test:champions-finish-online`은 실제 로컬 WebRTC 호스트/게스트 두 브라우저로 남은 시간·수비형 뱀·다음 라운드·효과 정리를 검사한다. 스크린샷은 `test-results/champions-finish/`에 저장한다. 단위 테스트는 일반 라운드의 3.6초 유지, 마지막 라운드 결과 화면, 중복 점수/전환 방지도 검사한다. Android 기기와 실제 상점 결제는 이 검증에 포함되지 않는다.

`test:phantom-motion`은 실제 미리보기 버튼을 눌러 리본의 렌더링 픽셀·문양의 정점 위치·입자의 위치가 시간에 따라 변하는지, 용 관절은 고정인지, 텍스처 디코딩·WebGL 오류·8초 정리·동작 줄이기를 검사한다. 스크린샷은 `test-results/phantom-motion/`에 저장한다. 순수 수학 테스트는 난수의 음수/오버플로, 리본 반경, 시간 경계, 점멸 주기, 멀티플레이용 결정성을 검사한다.

총별 장착과 내 스킨 탭에 들어갈 때 보유 정보를 다시 확인합니다. 잠긴 스킨을 눌렀을 때도 서버 보유 여부를 갱신하여, 다른 창·기기의 구매나 지급으로 보유하게 된 스킨을 같은 클릭으로 장착할 수 있습니다. 이미 진행 중인 조회가 있으면 새 조회를 이어서 실행하며, 다른 총·탭·계정으로 바뀐 뒤 도착한 이전 클릭 결과는 장착하지 않습니다. 미보유 스킨은 계속 미리보기만 가능합니다.

## 미리듣기

미리보기에서는 살펴보기 10.2초 구간을 재생하고, 마무리 음악은 3.03초 시점에 시작해 8초 마무리 종료에 함께 멈춘다. 게임 내 살펴보기 음악은 실제 살펴보기 동작이 끝나거나 중단되면 멈춘다.

미리듣기는 클릭 중 먼저 오디오를 활성화하고 음원 로딩을 기다린다. 실전 처치음의 1.5초 지연 폐기 규칙은 명시적인 미리듣기에 적용하지 않는다. 로딩·음소거·실패와 재시도를 화면에 알리고, 중지/다른 미리보기/탭 닫기 이후에는 늦게 도착한 요청이 다시 소리를 내지 않는다. 이전 살펴보기 프레임이 새 미리보기를 중지시키는 경쟁도 막는다.

`npm run test:phantom-audio`는 강제 `AudioContext.resume()` 없이 실제 버튼으로 첫 로딩 지연, 살펴보기/마무리 음악의 오디오 신호, 다섯 처치 연주, 중지/취소, 효과음 설정, 503 오류 후 재시도를 검사한다. 오디오 분석기의 신호를 확인하는 Chromium 검사이며 실제 휴대폰 스피커에서 들었다는 뜻은 아니다.

기존 설치형 웹 앱은 `/assets`를 URL별로 보관하므로 악기 목록 요청에 버전을 붙인다. 브라우저 검사는 악기 두 개가 빠진 이전 목록을 흉내 낸 응답을 두고 새 주소가 이를 피하는지도 검사한다.
