# 챔피언스 팬텀 연결

카빈에 `champions_atk`(공격·붉은빛), `champions_def`(수비·상아빛) 초월 스킨을 추가했다. 총 스킨 창 위쪽 **챔피언스** 탭 안에 전용 구매 화면이 있다. 그 안에서 색상, 발사음, 킬 배너·소리, 마무리, 살펴보기, 재장전을 미리 볼 수 있다. 보유한 색상을 누르면 카빈에 장착되며 기존 계정 저장과 방의 스킨 동기화를 사용한다. 미보유 색상은 미리보기만 가능하다. 초월 코인 700개로 구매하거나 기존 **뽑기** 탭에서 다른 스킨과 함께 0.00000000000000001% 확률로 획득한다. 별도 챔피언스 뽑기는 만들지 않는다. 관리자 지급 항목은 `carbine|champions_atk`, `carbine|champions_def`다.

피해량·탄창·연사·판정은 카빈 그대로다. 실제 마무리는 기존 규칙에 따라 일반전에서 마지막 적을 총으로 처치했을 때 한 라운드에 한 번 재생된다. 수류탄·능력·환경 피해, 다른 모드에는 적용하지 않는다. 모바일의 낮은 품질 설정과 동작 줄이기 설정을 따른다. 무기 살펴보기는 기존 Y 키와 터치 버튼을 사용한다. 재장전·꺼내기·사격은 기존 게임 손 모션을 유지하고 원본이 있으면 탄창·장전 손잡이 뼈대를 추가로 움직인다.

## 초월 등급과 초월 코인

무기고의 별도 **스킨 등급표**와 내 스킨 필터는 일반 → 희귀 → 영웅 → 전설 → **초월(5단계)** 순서다. 팬텀 공격·수비만 초월이며 기존 전설은 그대로다. 공유 데이터 `js/skin-tiers.js`를 게임·API·관리자 화면이 사용한다.

경기 완료 보상 기준(기존 경기 확인표와 60초 이상 경과)을 충족하면 승리·패배·무승부 모두 초월 코인 **1개**를 받는다. 연습/사격장·중도 이탈은 완료 보상을 만들지 않는다. 신규 코인 잔액은 0이며 기존 경기 수로 소급 지급하지 않는다. 골드와 별도로 계정/게스트 기록에 저장하고, 경기 확인표 소비·잔액 증가·재시도 영수증을 한 번에 저장해 재전송으로 중복 지급하지 않는다. 홈페이지와 초월 상점에서 잔액을 본다.

**공격/수비 스킨은 각각 700코인**이다. 초월 상점에서 두 번 눌러 구매를 확정하며, 서버는 가격을 700으로 고정한다. 골드는 사용하지 않는다. 부족한 잔액, 중복 보유, 동시 구매는 잔액을 음수로 만들지 않는다. 일일/주간 골드 상점에는 나오지 않으며 기존 관리자 지급 기능은 유지한다.

골드 뽑기에서는 초월 등급을 정확히 **0.00000000000000001% (1 / 10¹⁹)**로 별도 추첨한다. 암호학적 64비트 난수를 BigInt 정수로 읽고 범위 밖 표본을 다시 뽑아 나머지 연산의 편향을 없앤다. 보통 등급의 가중치와 독립적이며, 전설까지 전부 모았을 때의 보정이 초월로 자동 승급하지 않는다. 보유한 초월 스킨은 중복 지급하지 않는다. 일반 뽑기 가능 품목이 모두 소진되면 기존처럼 더 뽑을 수 없다.

## 원본 JAR 불러오기

무기고의 **원본 JAR 불러오기**에서 보유한 `ChampionsPhantom2026-0.1.0.jar`를 고른다. 무기 모델/텍스처, 숫자 키프레임 애니메이션, 킬 배너 프레임/엠블럼, 마무리 용 모델/텍스처를 읽어 Three.js에 맞게 변환한다. 모델은 뼈대별로 상자를 합쳐 렌더링한다. Minecraft 전용 카메라·손 위치·셰이더·자바 코드는 실행하지 않는다. 용 이동/나선/왕관과 배너 배치는 DFDF에 맞춘 연출이므로 원본 모드의 완전한 재현은 아니다.

가져온 데이터는 이 기기·브라우저·사이트 주소의 IndexedDB에만 저장되며 새로고침 후 복원된다. 계정 API와 다른 플레이어에게 전송하지 않는다. 방에는 기존과 동일한 스킨 식별자만 보낸다. 상대도 자신의 JAR을 불러오면 원본 외형을 보며, 불러오지 않은 브라우저는 게임 기본 카빈에 전용 색상/문양을 표시한다. **기본 외형으로**를 누르면 로컬 자산을 제거한다. 브라우저 데이터 삭제/시크릿 모드/주소 변경 시 다시 불러와야 한다. Chrome/Edge 등 `DecompressionStream('deflate-raw')` 지원 브라우저가 필요하다. 저장소 차단·용량 부족·손상된 파일은 상태 줄에 실패 이유를 표시하고 현재 팩을 유지한다.

첨부 JAR의 `fabric.mod.json`은 제작자 **Seafle**, 영상 사용 시 제작자 표기, 모드팩 포함 재배포 금지를 명시한다. 원본 JAR·추출 이미지·모델은 저장소/배포물/테스트 스크린샷에 포함하지 않는다. 불러오기 버튼 근처에도 제작자를 표시한다. 원본 파일은 사용자가 각자 보유한 복사본을 로컬에서 읽는 방식이다. 영상 공개 시에도 제작자를 표기한다.

원본에는 음원 파일이 없다. 발사·처치·헤드샷·마무리 소리는 DFDF Web Audio 합성 사운드이며 기존 효과음/음량 설정을 따른다. 원본 음원이나 원본 Minecraft 셰이더를 복제한 것으로 표시하지 않는다.

## 검증

```sh
npm run check
npm test
npm run dev
# 다른 터미널: Playwright 설치 및 필요하면 CHROME_BIN 지정
npm run test:phantom
# 선택: 보유한 JAR의 절대경로를 PHANTOM_JAR 환경변수에 설정한 뒤 다시 실행
```

`DFDF_PLAYWRIGHT_MODULE`, `CHROME_BIN`, `DFDF_BASE_URL`, `SHOT_DIR`는 기존 브라우저 테스트와 같다. `PHANTOM_JAR`가 없으면 별도 등급표/초월 필터/정확한 확률 표시/경기 보상 반영/700코인 구매 확인/기본 외형/소유권/장착/배너/마무리 정리/반응형을 검사한다. 있으면 실제 JAR 가져오기·텍스처 로딩·뼈대별 병합·계정 장착/로컬 자산 복원·제거도 검사한다. 스크린샷은 git에서 제외되는 `test-results/phantom`에만 저장된다. 테스트 구매/관리자 지급은 메모리 API 도구를 사용하며 실제 계정이나 결제를 변경하지 않는다.

브랜치와 PR은 검토용이다. 사용자 승인 전 병합하거나 운영 배포하지 않는다.
