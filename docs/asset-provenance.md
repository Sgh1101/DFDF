## 패키지 계약

- 황혼 지구: ASC2 레코드 포맷, 좌표는 제공된 원본의 블록 단위. dimensions/sourceCropMin/scale와 layout을 같은 manifest에 기록한다. world X/Z는 `(block - cropMin - dimensions/2) * horizontalScale`, Y는 바닥 기준 높이다. 모바일 파일은 동일 충돌 바이트를 보존하고 화면용 쿼드만 줄인다.
- 두 팀과 A/B 사이트를 명시적 원본 좌표/바닥 높이로 정하고, 실제 공격 스폰과 연결되는 다층 그래프를 검증한다. 현재 필수 좌표 이동은0m다. 맵을 바꾸면 기존 렌더·충돌·길찾기 상태를 정리한다. 하늘섬의 저장 키는 유지하며, 삭제된 사막과 전용 이벤트 기능은 되살리지 않는다.
- 과거 파일의 캐시를 제거하고 새 revision 쿼리를 사용한다. 현재 원본 파일과 과거 이미지가 섞여 보이지 않도록 지도 이미지도 재생성한다.

## 별도 허가가 도착했을 때 기록할 항목

권리자, 대상 파일/해시, 원본 URL, 웹 게임 사용·수정·재배포·광고 수익화 허용 범위, 허가일·유효 기간을 기록한다. 비공개 계약·개인정보는 공개 저장소에 넣지 않고 확인 가능한 내부 위치만 연결한다. 출처 기록만으로 허가를 대체하지 않는다.

## 현재 심사 준비와 배포 자료

`monetization-review.json`은 계정 심사·성인 신청자·대상 연령·지역/CMP·전체 자산 검토와 두 미확인 묶음의 파일 지문을 기록한다. 현재 전부 완료로 표시하지 않았고 광고는 OFF다. `npm run check:ads`는 현행 파일과 기록의 일치를 확인하며, `node scripts/check-ad-readiness.js --require-ready`는 미충족 상태에서 실패한다. 이 기록은 Vercel/Cloudflare 정적 배포에서 제외한다. 비공개 허가 문서나 개인 신원 자료를 JSON이나 공개 저장소에 넣지 않는다.

권리 미확인은 침해 확정과 다르지만 심사 적합성을 보증할 수도 없다. 광고를 꺼 두는 것 역시 기존 공개 자료의 사용권을 해결하지 않는다. 황혼 지구의 구조 및 나비칼 모션을 유지하라는 기존 요청과 독자 교체는 충돌하므로 사용자 허가 범위 답변 전에는 자동으로 맵·모션을 삭제/교체하지 않았다. 허가가 없으면 별도 독자 구조/뼈대/모션/합성음 교체 또는 공개 제공 제외를 결정해야 한다. 소스 첨부와 Git 이력은 보존한다.
