# 광고 도입 준비 작업 결과

기준일: 2026-11-01 (한국 시간). 작업 브랜치: `codex/adsense-readiness`.

**현재 상태: 로컬 구현과 Claude 최신 main 통합·관련 검증 완료. 광고를 게재하거나 main에 병합·배포하지 않았다.** Google 계정과 권리 확인이 남아 있으므로 광고 승인·수익화 완료를 뜻하지 않는다.

## 구현한 내용

- 개인정보 설정의 기본값을 필수 저장소만 사용으로 두고, 선택 저장·철회를 추가했다. 이 설정은 브라우저 선호이며 Google 인증 CMP를 대신하지 않는다.
- 이용규칙과 제작·출처 페이지를 추가하고, 홈페이지 및 공개 문서에서 접근할 수 있도록 연결했다.
- 문의·계정·활동·공통 운영 기록의 실제 보관 방식과 삭제 요청의 본인 확인·처리 범위를 공개 문서와 운영 지침에 맞췄다. 문의는 마지막 저장·수정 이후 90일이며 답변·상태 저장 때 기간이 다시 시작된다.
- `ads-config.json`과 순수한 광고 허용 판단 함수를 추가했다. 기본값은 비활성화이며 게시자 ID는 비어 있다. 계정 승인·권리·대상 연령·인증 동의가 확인되지 않으면 허용하지 않는다. **광고 SDK 로더는 없으므로 설정을 바꾸는 것만으로 광고가 나오지 않는다.**
- 일반 광고 후보는 소개 문서 6종(가이드·조작·모드·맵·요원·패치노트)으로 제한했다. 게임·상점·뽑기·로그인·채팅·문의·정책·관리자 경로는 제외했다.
- 하늘섬의 사용 허가가 확인되지 않은 schematic 형상을 외부 맵 입력 없이 만드는 자체 배치로 교체했다. 스폰·A/B 거점·충돌·경량 지형을 같은 manifest로 관리하고 실제 게임에서 미리보기를 다시 만들었다.
- 오래된 자산 캐시를 교체하고 폐기한 맵·미리보기 요청을 정리했다. Windows의 자산 줄바꿈 변환으로 해시가 깨지지 않도록 설정했다.

## Claude 작업과의 조정

사용자가 확인을 요청한 뒤 remote를 fetch하고 로컬 worktree·열린 PR·새 커밋을 비교했다. 최신 main은 `32a422e75d78c202f8203fbd5ce0051d50ab8647`이며 PR #112와 #113이 추가되어 있었다.

- [PR #112](https://github.com/Sgh1101/DFDF/pull/112): 하늘섬 단색 텍스처, 챔피언스 외형·마무리·음악 수정.
- [PR #113](https://github.com/Sgh1101/DFDF/pull/113): 소유자 요청에 따른 사막 마을·전용 이벤트 기능 삭제, 챔피언스 추가 다듬기.
- 사막 교체 후보는 최종 브랜치에서 제거했다. 사막 및 이벤트 기능을 다시 활성화하지 않는다.
- 클로드의 단색 블록 아틀라스·팔레트는 그대로 사용한다. 하늘섬의 배치·충돌·미리보기는 별도 자체 생성으로 바뀌므로 기존 지형과 같다고 주장하지 않는다.
- 챔피언스 자산·생성기·킬 물결 코드는 최신 main과 차이가 없다. 장착·보유·700코인·확률·8초 마무리 동작을 광고 준비 코드에서 바꾸지 않았다.
- [보안 PR #111](https://github.com/Sgh1101/DFDF/pull/111)은 아직 열려 있다. 새 비밀번호 길이·보고 모드 CSP 제안은 확인했지만 이 브랜치가 임의로 main에 병합하지 않는다.
- 다른 로컬 worktree의 미반영 변경은 발견하지 못했고, 해당 worktree들을 수정하지 않았다.

### 하늘섬 경량화 수치

원본 크기 쿼드 3,833 → 모바일 1,186(약 69% 감소), GPU 지형 버퍼 843,260 → 260,920바이트(약 69% 감소), 파일 98,788 → 35,260바이트(약 64% 감소)다. 두 파일의 충돌 데이터는 동일하다. 고정 카메라의 전체 프레임 삼각형은 두 임시 계정에서 각각 24,576 → 19,390과 42,124 → 36,938로 관측됐다. 감소량은 같아도 캐릭터·스킨 비용에 따라 전체 대비 비율이 달라지므로 고정된 감소율을 약속하지 않는다. 이 수치는 실제 휴대폰 FPS나 랙 개선율이 아니다.

최종 통과 실행에서 지형만 측정한 제출 삼각형은 7,614 → 2,428(약 68% 감소), 그리기 횟수는 28 → 13이었다. 전체 장면은 24,516 → 19,330이었다. 모바일→성능→모바일 전환 뒤 지형 수치가 복원되고 충돌·길찾기·플레이어 객체가 유지됨을 확인했다.

### 리뷰와 수정 기록

독립 리뷰는 이전 staged tree `b2248efb4249fdab087f0c48af2df9a51be52dad`를 대상으로 진행했다. 이후 발견한 Claude 통합 변경까지 독립 리뷰가 승인했다고 주장하지 않는다. 통합 diff는 구현자가 별도로 확인했고, 통합 소스로 단위·브라우저 검증을 실행한다.

1. 모바일 검사에 남은 폐기 지형의 고정 쿼드 수를 실제 새 manifest와 비교하도록 고쳤다. 기존 실패 로그는 보존한다. 작은 맵에서 캐릭터 고정 비용 때문에 전체 삼각형 25% 및 15% 감소 조건은 계정마다 성립하지 않는 것도 실제 측정으로 확인했다. 맵 이외 오브젝트의 표시를 잠시 껐다가 복원해 실제 지형의 삼각형·그리기 횟수를 따로 측정한다. 지형 쿼드·실제 제출 삼각형 40% 이상 감소, 메모리·충돌 동일성·재시도/경쟁 상태 검사도 유지한다. 전체 프레임 수치는 별도로 기록한다.
2. 공개 문의 보관 기간을 제출 후 최대 90일이라는 문구에서 마지막 저장·수정 기준 90일로 바로잡았다. 실제 API의 갱신 TTL과 일치하며, 생성 문서와 사이트 브라우저 검사로 확인한다. 낮은 영향의 문구 수정을 그대로 복제하는 별도 단위 검사는 만들지 않았다.
3. 이벤트 선택 UI 검사 보완 제안은 이후 Claude가 이벤트 기능 자체를 삭제한 변경으로 적용 대상이 사라졌다. API의 구 설정 호환 검사와 브라우저의 사막/이벤트 부재 검사를 유지한다.

## 실제 광고 전 남은 항목

1. 실제 신청인 자격·게시자 ID·사이트 승인 상태·주 도메인을 확인한다. 가짜 ID나 ads.txt를 만들지 않는다.
2. 이용자 연령층·대상 지역을 정하고, 필요한 Google 인증 CMP와 아동 관련 처리를 실제 계정에 설정한다. 설정의 검증·거절·철회 흐름을 확인한다.
3. 챔피언스 등 보호되는 외형·음악·상표와 관련한 미확인 권리 항목을 정리한다. 자체 생성이라는 이유만으로 권리가 정리됐다고 간주하지 않는다.
4. 위 사항을 완료한 뒤 별도 SDK/광고 슬롯 구현과 테스트 광고·실기기 검사를 한다. 일반 광고 클릭 보상, 경기 중 광고는 도입하지 않는다. H5는 별도 승인 절차다.
