# 마크X발로 맵

제공된 `ascent-final2021.schematic`를 DFDF의 실제 Three.js 장면과 캐릭터 이동·사격 판정에 연결한 맵입니다. **일반 요원 선택·방의 맵 목록에 마크X발로가 표시됩니다.** 별도 주소 없이 선택하고 전투 투입하면 불러옵니다.

`npm run dev`를 실행하고 `/play.html?ascent-trial=1`에서 **이 맵으로 연습 시작**을 누릅니다. 별도 작업 서버에서는 `PORT=3001`을 사용합니다. 계정/API 설정은 기존 개발 서버와 동일합니다. 자동 브라우저 검사는 테스트 계정을 메모리 API로 대체합니다.

일반 `/play.html`은 맵 이름을 등록하지만 선택하기 전에는 지형 바이너리를 다운로드하지 않습니다. 맵 선택 시 파일·원본 블록 텍스처를 검증해 준비하고, 준비 전에 전투 투입을 눌러도 이전 맵에서 시작하지 않도록 기다립니다. 방장과 손님의 경기 시작에도 같은 준비 절차를 적용합니다. 기존 `/play.html?ascent-trial=1` 체험 주소도 유지합니다. 모바일 실기기 성능·다른 경기 모드의 목표물 배치는 별도 검증이 필요합니다.

## 보존한 데이터와 변환

- 원본 압축 파일을 `sources/maps/ascent-final2021.schematic`에 그대로 보관했습니다. SHA-256: `b987d994b5aa01e0b614b5e7d92a4b8f41f7cf6ecab1daddd5ba3fc4cf1b9c28`.
- Alpha NBT, 원본 배열 324 × 212 × 293, 공기 외 244,407개 블록입니다. 빈 여백만 잘라 206 × 115 × 223의 점유 영역을 사용합니다. WorldEdit의 멀리 떨어진 월드 좌표는 게임 중심으로 평행 이동합니다.
- 블록 한 변은 1.25 m입니다. 높이·길이·폭에 같은 배율을 적용하며 반 블록 계단 0.625 m가 캐릭터의 0.68 m 보행 한계에 맞습니다.
- 전체 블록의 내부 면을 제거하고 같은 블록 상태의 외부 면을 합칩니다. 부분 블록은 메타데이터에 따른 직선 계단·상하 반 블록·카펫·눈·문·트랩도어·연결 난간 형태로 만듭니다. 렌더링과 충돌은 같은 부분 블록 상자를 사용합니다. 식물은 투명도가 있는 교차 면으로 렌더링합니다.
- ASC2 출력은 302,566개 사각 면, 44,380개 충돌 상자, 7,794,160바이트입니다. 런타임에서는 불투명·투명 지형을 97개 공간 묶음으로 렌더링하고, 지면·총알·몸 충돌 검색에는 공간 해시를 사용합니다. 파일 해시를 로딩 시 확인합니다.
- 사용자가 선택한 기본 텍스처를 로컬 Minecraft 1.20.1 클라이언트 JAR에서 추출했습니다. 블록 PNG 239개는 원본 바이트 그대로 보존하고 SHA-256 목록을 제공합니다. 렌더링용 아틀라스는 원본 16픽셀 프레임을 확대·축소하지 않고 배치하며 합쳐진 면에서도 블록마다 반복합니다. 잔디는 기본 바이옴 색과 원본 오버레이를 합성합니다. 블록 ID와 데이터 값에 따라 돌·화강암·나무·윗면·옆면 등이 구분됩니다.
- 전체 Minecraft 블록 모델을 실행한 결과는 아닙니다. 계단 안쪽·바깥쪽 모서리, 일부 난간·문 경첩, 표지판·현수막·머리 등 NBT 장식은 단순화됩니다. 물·용암 등 애니메이션 텍스처는 첫 프레임을 사용합니다. 레드스톤·타일 엔티티·명령 블록·Java 코드는 실행하지 않습니다.

## 게임 연결

실제 캐릭터 크기로 통과 가능한 지면을 0.625 m 격자로 검사하고, 보행·단차 판정을 통과한 방향만 연결합니다. 가장 큰 양방향 도로망에 시작점과 A/B 목표 지점을 배치합니다. 이는 시험용 배치이며 원본 게임의 공식 스폰·사이트 좌표를 가져온 것이 아닙니다. 지형 자체를 깎아 길을 만들지는 않습니다.

봇은 지면 높이를 반영한 경로를 사용합니다. 목표별 역방향 이동 경로를 최대 12개 보관해 같은 목표로 향하는 봇들의 탐색을 재사용합니다. 보행 격자는 정적 지형 기준입니다. 임시 능력 벽 등으로 인한 경기 중 우회와 전체 AI 경기 품질은 추가 검토 대상입니다.

다른 맵을 불러오면 시험 지형의 기하·재질을 해제하고 원래 길찾기 간격·이동 함수·내비게이션 노드 동작으로 돌아갑니다. 카빈 챔피언스, 킬 사운드, 마무리와 클로드의 다른 브랜치는 이 작업에서 변경하지 않습니다.

## 재생성과 검증

Node.js 20 이상으로 지형을 재생성합니다. 기본 텍스처를 다시 추출할 때만 Python과 Pillow, 로컬 Minecraft 클라이언트 JAR이 필요합니다. 생성된 파일이 이미 있으면 추출을 반복할 필요가 없습니다.

```sh
python scripts/package-block-textures.py <Minecraft-1.20.1-client.jar>
npm run import:ascent
node --test tests/schematic.test.js
npm run check
npm test
npm run test:ascent
```

브라우저 검사에는 Playwright/Chromium과 실행 중인 개발 서버가 필요합니다. `DFDF_BASE_URL`, `DFDF_PLAYWRIGHT_MODULE`, `CHROME_BIN`을 기존 브라우저 검사와 동일하게 설정합니다.

검사는 화면의 시작 버튼을 직접 클릭한 뒤 실제 키보드 이동, 시작점·목표 간 경로, 수백 개 지점을 통한 캐릭터 물리 이동과 고저차, 몸 충돌, 벽 뒤 적에 대한 실제 hitscan 차단, 맵 전환 자원 해제, 일반 진입 시 추가 데이터 미다운로드를 검사합니다. 브라우저 화면은 `test-results/ascent-play.png`에 저장합니다. 소프트웨어 렌더링 Chromium의 결과를 실제 휴대폰 프레임 성능으로 간주하지 않습니다. Android·스토어 구매 검사는 이 작업 범위가 아닙니다.

2026-10-18 로컬 실행 결과: 문법 검사 131개 스크립트 통과, 단위 검사 106개 중 105개 통과·실제 Redis 통합 검사 1개 생략. Chromium에서 실제 키보드 이동과 505개 경로 지점의 이동 물리를 통과했습니다. 원본 고저차와 천장 점프 충돌, 벽 뒤 적 피해 0, 봇 9/9 이동, 지형 97개 기하 자원 해제, 일반 진입 시 시험 데이터 요청 0을 확인했습니다. Android·온라인 WebRTC·실제 구매 검사는 실행하지 않았습니다.
